# TRAE SOLO 平台使用指南

## 三端协同
- 桌面版：多智能体规则配置、工程化流水线搭建、复杂编码调试、大文件处理（独立运行架构，深度性能优化）
- 网页版：临时文档处理、快速代码验证、无本地客户端时的轻量任务
- 移动版：按住说话下达指令（比打字快3倍）、跨设备调度桌面版执行任务、实时监控任务状态
- 三端联动：移动版下达指令→桌面版执行→桌面版验收，任务和产物自动同步

## 模式匹配
- MTC模式：非编码类任务（文档/PPT/数据分析/流程设计/多智能体协作），用MTC搭建智能体体系和规则
- Code模式：编码类任务（代码编写/调试/重构/代码审查），Coding Agent能力更强，直接与Git集成
- 同一项目两种模式无缝切换，无需重新创建
- 多智能体工程：MTC搭建体系+规则，Code处理编码任务

## 云端智能体
- 适用：本地环境配置复杂、耗时长的代码分析运行调试、需要统一运行时的团队协作、本地性能不足
- 优势：释放本地CPU内存、统一运行环境确保结果一致、大型代码库分析审查速度比本地快3-5倍
- 限制：无法访问本地文件（需先上传）、敏感数据用本地处理、超大任务拆分后分批执行

## 流程优化
- 复杂任务拆解为多个小步骤逐个下达，准确率比一次性下达高30%以上
- 指令明确具体，包含输入输出要求和约束条件
- 提前配置全局规则和角色规则，减少每次指令的重复描述
- 常用模板和规则文件保存为项目模板直接复用
