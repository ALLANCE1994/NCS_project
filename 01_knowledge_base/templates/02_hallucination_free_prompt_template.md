## 模板说明

本模板用于指导用户向智能体下达任务时，使用精准、无歧义的提问方式，从源头减少AI幻觉发生概率。

**核心原则**：
1. 明确知识来源
2. 界定任务边界
3. 指定参数约束
4. 定义验收标准
5. 列出禁止事项

---

## 一、通用任务模板

### 标准格式

```markdown
@目标智能体 请完成以下任务：

【任务目标】一句话描述要做什么（明确、具体）
【知识来源】请基于《XXX文档》第X章 / 项目知识库中的XXX内容
【改动边界】仅处理XXX，不涉及YYY
【参数约束】具体参数范围：XXX
【输出要求】交付物清单：XXX
【验收标准】如何验证完成：XXX
【禁止事项】不进行XXX操作

请先确认理解，再开始执行。
```

## 三、危险提问方式对照表

| 危险提问方式 | 幻觉风险 | 正确提问方式 |
|-------------|---------|-------------|
| "帮我写一个脉冲模块" | 无边界，AI可能编造参数 | "请基于《脉冲卡技术手册》第3章，编写一个频率范围100kHz-10MHz、占空比可调的脉冲发生模块" |
| "设计一个ODMR实验" | 无约束，AI可能编造条件 | "请基于《NV色心实验指南》第5章ODMR实验方案，设计微波扫频范围2.8-3.0GHz、步进1MHz的实验流程" |
| "优化一下代码" | 无目标，AI可能过度修改 | "请仅优化XXX模块的时序路径，目标：Setup Slack > 0ns，不改动其他模块" |
| "参考一下其他方案" | AI可能套用不相关方案 | "请仅参考本项目知识库中的XXX方案" |
| "大概就行" | AI可能随意发挥 | "请严格按照XXX标准执行" |
| "你看着办" | AI可能做出错误假设 | "请按以下步骤执行：1)... 2)..." |
| "用最好的方案" | "最好"无定义，AI可能过度设计 | "请使用满足XXX约束的最简方案" |
| "帮我设计一个..." | 无边界，AI可能编造参数 | "请基于XXX文档，设计一个参数范围为...的系统" |

## 五、常见问题解答

### Q1: 如果不知道知识来源怎么办？
**A**: 明确告知智能体"当前知识库中无对应专业资料"，请求暂停执行，等待上传相关文档。

### Q2: 如果任务涉及多个知识来源怎么办？
**A**: 明确列出所有知识来源，并说明各来源对应的内容范围。

### Q3: 如果参数范围不确定怎么办？
**A**: 指定"参数范围待确认"，要求智能体先输出参数建议并标注来源，确认后再执行。

### Q4: 如果需要智能体提供建议怎么办？
**A**: 明确要求"请基于知识库提供建议方案，并标注每个建议的知识来源"。
