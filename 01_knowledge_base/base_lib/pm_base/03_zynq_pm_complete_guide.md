#### 2.1.2 三点估算法（考虑不确定性）

```
公式：工期 = (乐观 + 4×最可能 + 悲观) / 6

示例：Vivado工程搭建
- 乐观：5天（有经验，无复杂IP）
- 最可能：10天（标准流程）
- 悲观：20天（首次开发，需学习）

计算：(5 + 4×10 + 20) / 6 = 10.8天 ≈ 11天
建议工期：11天 + 2天缓冲 = 13天
```
