#### 2.1.2 三点估算法（考虑不确定性）

```
公式：工期 = (乐观 + 4×最可能 + 悲观) / 6

示例：Vivado工程搭建
- 乐观：5天（有经验，无复杂IP）
- 最可能：10天（标准流程）
- 悲观：20天（首次开发，需学习）

计算：(5 + 4×10 + 20) / 6 = 10.8天 ≈ 11天
建议工期：11天 + 2天缓冲 = 13天
```

#### 5.3.1 约束文件分层架构

```tcl
# pin.xdc - 引脚分配（物理约束）
# 由@H根据原理图编写
set_property PACKAGE_PIN R11 [get_ports {led[0]}]
```

#### 5.3.2 时序收敛检查标准

| 检查项 | 通过标准 | 处理措施 |

| TNS (Total Negative Slack) | = 0ns | 为负需优化 |
| WHS (Worst Hold Slack) | > 0ns | 为负需优化 |
| 未约束路径 | 0条 | 必须全部约束 |

### 8.2 镜像烧录标准流程

**【适用阶段】**：交付部署阶段  
**【使用方法】**：按步骤执行，验证确认  
**【参考依据】**：正点原子快速体验指南

#### 8.2.1 TF卡镜像烧录

```
1. 准备Micro SD卡（Class 10，8GB+）
2. 使用SD Card Formatter格式化（FAT32）
3. 使用Win32DiskImager写入镜像
4. 设置BOOT_CFG拨码开关为TF卡模式（ON-OFF）
5. 插入TF卡，上电启动
6. 验证启动成功标志：
   - 4颗LED点亮
   - 核心板LED1心跳模式
   - 串口终端出现root提示符
```

#### 8.2.2 QSPI固化流程

```
1. 从TF卡启动系统
2. 执行固化命令（根据具体镜像类型）
3. 等待固化完成（约5-10分钟）
4. 断电，切换BOOT_CFG为QSPI模式（ON-ON）
5. 上电验证从QSPI启动
6. 确认系统功能正常
```
