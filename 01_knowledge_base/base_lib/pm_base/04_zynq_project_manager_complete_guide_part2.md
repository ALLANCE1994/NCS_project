### 9.2 风险评估与应对策略

**【适用阶段】**：风险识别后，制定应对计划  
**【使用方法】**：定性+定量评估，制定应对策略  
**【参考依据】**：风险管理标准实践

#### 9.2.1 风险等级矩阵

```
        影响程度
        低    中    高
可    低  🟢    🟢    🟡
能    中  🟢    🟡    🔴
性    高  🟡    🔴    🔴

🟢 低风险：监控即可
🟡 中风险：制定应对计划
🔴 高风险：立即制定详细应对方案，定期汇报
```

#### 9.2.2 应对策略选择

| 策略 | 适用场景 | ZYNQ项目示例 |
|------|---------|-------------|
| **规避** | 风险影响太大，改变方案 | 时序要求高时，改用纯PS方案 |
| **转移** | 风险可外包或保险 | 复杂PCB设计外包 |
| **减轻** | 降低风险概率或影响 | 增加仿真验证，减少上板调试 |
| **接受** | 风险可控，成本效益高 | 低概率风险，预留应急时间 |

```
1. 准备阶段
   - 作者准备评审材料
   - 确定评审人员（3-5人）
   - 分发材料，预审时间2-3天

2. 评审会议
   - 作者介绍（15分钟）
   - 评审人员提问（30分钟）

3. 整改阶段
   - 作者根据问题清单整改
   - 评审人员确认整改结果
   - 关闭问题或重新评审
```
