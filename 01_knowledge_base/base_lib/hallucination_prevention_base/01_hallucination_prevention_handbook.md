## 第一章：幻觉基础知识

### 1.1 什么是AI幻觉

AI幻觉是指AI系统生成看似合理但实际上不正确、虚构或与事实不符的内容。在工程项目中，AI幻觉可能导致：

- 错误的技术参数
- 虚构的硬件配置
- 编造的解决方案
- 误导性的技术描述

### 1.2 幻觉类型分类

| 类型 | 定义 | 典型表现 |
|------|------|----------|
| **虚构型** | 编造不存在的信息 | 虚构引脚、编造API、杜撰参数 |
| **篡改型** | 篡改原文核心原意 | 修改参数值、曲解技术描述 |
| **延伸型** | 过度脑补超出原文 | 原文说"可能"输出为"一定" |
| **混淆型** | 跨领域知识错误套用 | A芯片参数套用到B芯片 |
| **遗漏型** | 关键信息缺失 | 遗漏约束条件、遗漏安全检查 |

### 1.3 幻觉产生原因

1. **知识来源缺失**：知识库中无对应内容，AI自行编造
2. **指令边界模糊**：用户指令不清晰，AI自主脑补
3. **跨领域混淆**：AI将其他领域知识错误套用
4. **过度延伸**：AI基于有限信息过度推理
5. **训练数据干扰**：AI训练数据与项目实际不符

## 第二章：硬件开发幻觉预防

### 2.1 FPGA引脚定义幻觉

**幻觉表现**：
- 虚构不存在的引脚名称
- 编造引脚功能描述
- 错误的引脚电平定义

**预防措施**：
```
✅ 必须基于知识库中的引脚定义文档
✅ 所有引脚定义必须标注来源
✅ 使用前核对官方数据手册
❌ 禁止凭记忆或经验编造引脚
```

**正确示例**：
```vhdl
-- 知识来源：《ZYNQ-7000数据手册》第3章
-- 引脚定义基于官方文档
entity pulse_generator is
    port (
        clk_100m : in  std_logic;  -- 100MHz时钟，来源：数据手册第3.2节
        rst_n    : in  std_logic;  -- 复位信号，来源：数据手册第3.2节
        pulse_out: out std_logic   -- 脉冲输出，来源：项目设计文档第2章
    );
end entity;
```

### 2.2 IP核配置幻觉

**幻觉表现**：
- 编造不支持的IP参数
- 虚构IP配置选项
- 错误的IP使用方法

**预防措施**：
```
✅ 必须基于官方IP文档或知识库
✅ 配置参数必须标注来源
✅ 使用前验证IP是否支持该配置
❌ 禁止使用未文档化的参数
```

### 2.3 时序约束幻觉

**幻觉表现**：
- 杜撰时序参数
- 编造时钟频率

**预防措施**：

```
✅ 时序裕量必须标注计算依据
❌ 禁止编造时序参数
```

## 第七章：幻觉自查清单

### 7.1 输出前自查

在输出任何技术内容前，请确认：

- [ ] 是否检索了知识库？
- [ ] 是否找到了匹配的权威资料？
- [ ] 是否标注了知识来源？
- [ ] 参数数值是否与原文一致？
- [ ] 技术描述是否准确？
- [ ] 是否存在过度延伸？
- [ ] 是否存在跨领域混淆？

### 7.2 幻觉预警信号

| 预警信号 | 可能的幻觉类型 | 建议行动 |
|----------|----------------|----------|
| 无知识来源标注 | 全类型 | 暂停输出，检索知识库 |
| 参数过于"完美" | 虚构型 | 核对原文参数范围 |
| 描述过于绝对 | 延伸型 | 检查原文是否有条件限定 |
| 跨领域引用 | 混淆型 | 确认是否适用于当前领域 |
| 遗漏边界条件 | 遗漏型 | 检查原文约束条件 |
| "我记得"开头 | 虚构型 | 必须检索知识库验证 |

## 第八章：典型案例分析

### 案例1：虚构FPGA引脚

**幻觉内容**：
```vhdl
-- 错误示例
pulse_out : out std_logic;  -- 脉冲输出引脚，位于Bank35
```

**问题分析**：
- 未基于官方文档定义引脚
- 虚构引脚位置信息

**正确做法**：
```vhdl
-- 正确示例
-- 知识来源：《ZYNQ-7000数据手册》第3章
-- 引脚定义基于官方文档第3.2节
pulse_out : out std_logic;  -- 脉冲输出引脚，位置待XDC约束确定
```

### 案例2：篡改参数数值

**幻觉内容**：
```
NV色心零场分裂 D = 2.88 GHz
```

**问题分析**：
- 篡改原文参数数值
- 未标注来源

**正确做法**：
```
【参数来源】
- 零场分裂 D = 2.87 GHz
- 来源：《金刚石NV色心量子传感原理》第2章
- 参考文献：Dolde et al., Nature Physics (2011)
```

### 案例3：过度延伸

**幻觉内容**：
```
该方案一定能提高系统性能
```

**问题分析**：
- 原文只说"可能提高"
- 过度延伸为"一定"

**正确做法**：
```
根据《XXX文档》第X章，该方案可能提高系统性能，
具体效果需实际验证。
```
