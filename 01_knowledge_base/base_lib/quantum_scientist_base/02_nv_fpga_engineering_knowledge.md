## P1 NV系综磁力测量集成化可扩展实验系统

> **来源**：Rev. Sci. Instrum. 94, 014703 (2023)，合肥工业大学 + 浙江实验室
> **文件**：`014703_1_online.pdf`
> **核心定位**：基于FPGA替代SG/LIA/PID/示波器等多台商用仪器的NV系综磁力测量集成平台

### 核心工程参数

| 参数 | 值 |
|------|-----|
| FPGA型号 | Xilinx Zynq-7010 SoC (STEMlab 125-14) |
| DSP切片 | 80个 DSP48E1 |
| BRAM | 60 x 36KB |
| ADC/DAC | 14位双通道 LTC2145CUP-14 / AD9767 |
| 主时钟 | 125 MHz |
| 数据总线 | 128位（9通道x14位并行） |
| 通信 | 千兆以太网 UDP，带宽910 Mbps |
| 开发工具 | Vivado 2019.2 |

### FPGA模块架构

```
┌─────────────────────────────────────────────┐
│                  PS端 (ARM Cortex-A9)         │
│  Standalone C程序 + LWIP 2.1.1 + UDP通信     │
└──────────────┬──────────────────────────────┘
               │ AXI + DMA + DDR3
┌──────────────▼──────────────────────────────┐
│                  PL端                         │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐     │
│  │ DAQ模块  │ │ LIA模块  │ │ SG模块   │     │
│  │ 连续采样 │ │ 锁相放大 │ │ DDS信号  │     │
│  │ 示波器   │ │ 单/双相  │ │ 发生器   │     │
│  └──────────┘ └──────────┘ └──────────┘     │
│  ┌──────────┐                               │
│  │ PID模块  │                               │
│  │ 离散位置式│                               │
│  └──────────┘                               │
└─────────────────────────────────────────────┘
```

### 关键设计细节

**DDS信号发生器**：
- 32位相位累加器，频率范围29.1 mHz ~ 62.5 MHz
- 仅存储1/4周期波形节省BRAM资源
- 支持正弦/三角/锯齿/PWM，可扩展任意波形

**数字LIA**：
- DSP48E1实现14位乘法混频
- FIR低通滤波器 + 滑动平均滤波器（基于Block RAM）
- 可配置：双通道单相 / 单通道双相

**PID控制**：
- 离散位置式算法，控制带宽约40 ns

### NV实验适配

| 实验类型 | 支持 | 说明 |
|----------|------|------|
| CW-ODMR | ✅ | 微波频率扫描 |
| Lock-in ODMR | ✅ | FM调制+锁相，同时激发三个¹⁴N超精细跃迁 |
| 光学腔锁定 | ✅ | PDH类锁定，腔精细度F=78 |
| Rabi/T1/T2 | ❌ | 未涉及 |

### 核心性能指标

- **磁场灵敏度**：750 pT/√Hz（Lock-in NV磁力测量）
- **腔增强后**：15 nT/√Hz
- **微波调制频率**：fm = A‖ = 2.16 MHz

### 工程价值与适配XC7Z020

- ✅ **直接可复用**：Zynq-7010 → Zynq-7020，资源充裕（DSP 80→220，BRAM 60→140）
- ✅ DAQ/LIA/SG/PID四大模块可直接作为基础框架
- ✅ AXI+DMA+UDP数据通路完整可复用
- ⚠️ 建议PS端升级为Linux支持更复杂处理
- ⚠️ Vivado版本兼容性需验证（论文用2019.2 vs 项目用2020.2）

## P3 纳秒级反馈速度的FPGA NV色心电荷态读出设备

> **来源**：AIP Advances 13, 115324 (2023)，合肥工业大学 + 浙江实验室
> **文件**：`115324_1_5.0154343.pdf`
> **核心定位**：集成脉冲发生器+时间标签器+实时反馈逻辑的单FPGA闭环量子态控制系统
> **开源**：https://github.com/leaferfoeget/real-time-feedback

### 核心工程参数

| 参数 | 值 |
|------|-----|
| FPGA型号 | Xilinx Artix-7 xc7a75tfgg484-1 |
| 工作时钟 | 500 MHz |
| 脉冲分辨率 | 1 ns |
| 时间标签精度 | 10.5 ps 单次RMS |
| 反馈延迟 | **8 ns（闭环）** |
| 脉冲输出抖动 | 11.7-14.7 ps |
| 数字I/O | 24通道（20路脉冲+2路时间标签+2路HS） |
| FIFO深度 | 8192并发事件 |

### FPGA模块架构

```
┌─────────────────────────────────────────────┐
│              20通道脉冲流发生器                │
│  80位dout(4:1序列化) + 30位count + 控制位    │
│  500 MHz双边沿解码，支持序列切换              │
├─────────────────────────────────────────────┤
│              2通道同步时间标签器               │
│  TDL-TDC进位链抽头延迟线                     │
│  10.5 ps精度，4 ns死时间                     │
├─────────────────────────────────────────────┤
│              自定义反馈逻辑模块                │
│  MAD算法硬件实现                             │
│  keep/skip/loop操作                          │
├─────────────────────────────────────────────┤
│              DDR3控制器 + 仲裁模块             │
└─────────────────────────────────────────────┘
```

### MAD算法核心

- 检测窗口可配置：100 ns ~ 655.5 ms
- 动态更新似然比矩阵M(n,t)
- 上阈值α → 判定NV-，生成trigger1跳出序列
- 下阈值β → 判定NV0，生成trigger2
- NV-读出保真度：92.7%（MAD）vs 83.4%（阈值法），时间减少约50%

### NV实验适配

| 实验类型 | 支持 | 说明 |
|----------|------|------|
| 电荷态读出 | ✅ | 核心功能，单次自适应判别 |
| Rabi振荡 | ✅ | 增强型，对比度31.7%→35.0% |
| Hahn Echo | ✅ | 理论分析 |
| ODMR/T1/T2/Ramsey | ❌ | 未直接涉及 |

### 工程价值与适配XC7Z020

- ✅ **开源代码**，可直接参考和修改
- ✅ TDL-TDC（10.5 ps精度）可直接复用于高精度时间测量
- ✅ 20通道脉冲流（1 ns分辨率）是单NV精密控制核心
- ✅ 8 ns闭环反馈延迟为业界领先水平
- ✅ xc7a75t（33K逻辑单元）→ XC7Z020（53K逻辑单元），资源充裕
- ⚠️ 建议利用PS端替代USB 3.0通信，改用千兆以太网
- ⚠️ 进位链TDC需针对XC7Z020重新校准延迟特性
- ⚠️ 500 MHz时钟时序收敛需仔细约束

## P4 混合信号数据采集系统(ODMR)

> **来源**：arXiv:2201.06011v1, 2022年1月，合肥工业大学
> **文件**：`2201.06011v1.pdf`
> **核心定位**：混合信号（模拟+数字）同步采集与多路信号发生

### 核心工程参数

| 参数 | 值 |
|------|-----|
| FPGA型号 | Xilinx Zynq XC7Z010 |
| ADC | LTC2145CUP-14, 14位双通道, 125 MSPS |
| DAC | AD9767, 14位 |
| 时钟 | 125 MHz |
| 模拟通道 | 4路（2输入+2输出） |
| 数字通道 | 16路可选 |
| DDR3 | 512 MB |
| 通信 | 千兆以太网 UDP |

### FPGA模块架构

- **SAP（同步采集与处理）**：2路AI + 3路DI同步采集，FIFO→DSP→128-bit编码→DMA→DDR3
- **MSG（多路信号发生器）**：PWM数字脉冲（8 ns分辨率）+ DDS正弦RF（0~50 MHz）
- **HSC（高速通信）**：千兆以太网UDP

### SAP双模式设计

| 模式 | 说明 |
|------|------|
| 序列模式 | N个实验点按S(全局重复)和R(单点重复)采集 |
| 连续模式 | 64KB BRAM循环缓冲，最多4096采样点 |

### NV实验适配

| 实验类型 | 支持 | 说明 |
|----------|------|------|
| cw-ODMR | ✅ | NV系综，1000点，2790~2950 MHz |
| Rabi振荡 | ✅ | NV系综 |
| Lock-in检测 | ✅ | 单NV，FM调制解调 |
| T1/T2/Ramsey | ❌ | 未涉及 |

### 工程价值与适配XC7Z020

- ✅ 混合信号同步采集架构通用性强
- ✅ SAP序列/连续双模式可直接复用
- ✅ XC7Z010 → XC7Z020资源充裕
- ⚠️ DDS输出带宽受限（实际0~50 MHz），精确脉冲需外接设备
- ⚠️ DDR3控制器需在Vivado中正确配置

## P6 快速磁场测量系统(Chen 2026)

> **来源**：J. Phys.: Conf. Ser. 3216 (2026) 012006，合肥工业大学
> **文件**：`Chen_2026_J._Phys.__Conf._Ser._3216_012006.pdf`
> **核心定位**：基于ZYNQ7020的频率捷变微波+正交锁相解调快速磁场测量
> **⚠️ 直接使用ZYNQ7020，参考价值最高**

### 核心工程参数

| 参数 | 值 |
|------|-----|
| FPGA型号 | **Xilinx ZYNQ7020 SOC (ALINX载板)** |
| ADC | 16位, 80 MSPS |
| DAC | 16位 (AN9767, ALINX) |
| 微波信号源 | CN0511 (ADI), 内含AD9166 |
| SPI速率 | 100 MHz |
| 载波频率 | 10 MHz |
| 调制频率 | 10 kHz |
| 调制深度 | 2 MHz |
| 频率跳变时间 | **< 1 μs**（实测980 ns） |
| 解调响应时间 | **< 80 μs**（0%→90%稳态） |

### FPGA模块架构

- **频率捷变微波模块**：高速SPI(100MHz) → CN0511的48-bit NCO → 双ROM核DDS → DAC → 混频器 → 微波放大
- **信号解调模块**：正交数字锁相放大器 → 级联FIR滤波器 → 离散时间RC滤波器组

### 微波链路

```
FPGA ROM核1(10kHz调制) + ROM核2(载波叠加)
    → DAC(AN9767) → SSB2040A混频器 → TLPA0.5G-6G放大器(43dB)
    → 微波输出
```

### 噪声抑制方案

- **相消噪声抑制**：分束器将532nm激光分为参考信号，时域消除激光功率噪声
- **低噪声前级运放**：1.1 nV/√Hz
- **级联滤波**：FIR + 离散时间RC滤波

### NV实验适配

| 实验类型 | 支持 | 说明 |
|----------|------|------|
| cw-ODMR | ✅ | 快速磁场测量，毫秒级响应 |
| Rabi/T1/T2 | ❌ | 未涉及脉冲序列 |

### 核心性能指标

- **磁场灵敏度**：> 8.30 nT/√Hz
- **电流测量精度**：0.08%（0.5~10 A范围）
- **ODMR谱线斜率**：7.28 mV/MHz（2.834 GHz处）

### 工程价值与适配XC7Z020

- ✅ **芯片平台完全一致**（ZYNQ7020），参考价值最高
- ✅ 频率捷变方案（100MHz SPI + 48-bit NCO，<1μs跳变）可直接复用
- ✅ 正交锁相级联滤波架构（FIR + RC，80μs解调）可直接复用
- ✅ 相消噪声抑制为通用光学噪声抑制方案
- ✅ 面向工业应用（电力系统电流测量），工程化程度高
- ⚠️ CN0511信号源和AN9767 DAC为ALINX配套板卡，需额外采购
- ⚠️ 正交锁相放大器的DSP资源需求需评估，建议使用FIR Compiler IP核

## P7 基于NV色心的标量磁场测量(IEEE TIM)

> **来源**：IEEE Trans. Instrum. Meas., Vol.75, 2026 (1003409)，南京邮电大学
> **文件**：`Scalar_Magnetic_Field_Measurement_Based_on_Nitrogen-Vacancy_Centers_in_Diamond.pdf`
> **核心定位**：频率分段采集策略实现快速标量磁场测量

### 核心工程参数

| 参数 | 值 |
|------|-----|
| ADC | LTC2208（高速） |
| 接口 | SMA连接器输出脉冲 |
| 上位机 | LabVIEW |
| 测量范围 | 2-45 mT |
| 脉冲时序 | 激光1000 ns, MW 100 ns(优化后), 周期2000 ns |

### 核心创新：频率分段采集

- 不扫描全频段，仅针对8个共振峰附近分段采集
- 显著减少总采集时间
- MW脉冲从250 ns优化至100 ns，FWHM从12.86→12.23 MHz

### 核心性能指标

- **测量噪声**：359.58 nT/√Hz

- **统一时钟**：主控模块为所有模块提供时钟，避免数据丢失和时钟抖动

- 参考电压：ADR3412提供1.2V

- 系数放大8192取整，右移实现除法
- 避免浮点运算，纯整数实现

- ✅ SDRAM缓冲方案可利用ZYNQ片上DDR控制器
- ✅ 整体资源需求不高，XC7Z020完全满足
- ⚠️ STM32F103微波源控制可完全由PS端Linux替代
- ⚠️ 一键操作界面可基于PYNQ框架实现

# 第四部分：XC7Z020CLG400-2适配指南

## 4.1 资源评估

| 资源 | XC7Z020CLG400-2 | 推荐分配 |
|------|-----------------|---------|
| 逻辑单元 | 53,200 | PL端逻辑 |
| DSP48E1 | 220 | DLIA×2 + DDS + FIR |
| BRAM (36Kb) | 140 | FIFO + 波形ROM + 滤波器 |
| DDR3 | PS端硬核控制器 | 数据缓冲 |
| GPIO | Bank 33/34 | 脉冲输出 + 触发 |

## 4.2 适配优先级

| 优先级 | 模块 | 参考论文 | 理由 |
|--------|------|---------|------|
| **P0** | CORDIC DLIA | P8,P9 | 资源极低，核心信号处理 |
| **P0** | DDS信号发生器 | P1 | 基础模块，资源低 |
| **P1** | 脉冲序列发生器 | P3 | 单NV精密控制核心 |
| **P1** | 数据采集(DAQ) | P1,P4 | 荧光信号采集 |
| **P2** | 正交锁相+级联滤波 | P6 | 快速解调 |
| **P2** | 频率捷变SPI | P6 | 快速频率切换 |
| **P3** | TDL-TDC时间标签器 | P3 | 高精度时间测量 |
| **P3** | PID控制 | P1 | 闭环反馈 |
| **P4** | FPGA相机 | P2 | 宽场成像扩展 |

## 4.3 关键注意事项

1. **时钟管理**：使用MMCM/PLL生成所需时钟（125MHz主时钟、500MHz脉冲时钟），确保同一晶振源
2. **时序约束**：500MHz路径需仔细约束，建议先在较低频率验证功能
3. **PS-PL接口**：AXI-Lite用于寄存器配置，AXI-DMA用于高速数据流
4. **DDR3**：使用PS端硬核控制器，不占用PL资源
5. **I/O Bank电压**：确认脉冲输出Bank电压兼容性（3.3V TTL需电压转换）
6. **进位链TDC**：不同器件延迟特性不同，需针对XC7Z020重新校准
7. **开发工具**：项目锁定Vivado 2020.2，论文中部分使用2019.2需注意兼容性
