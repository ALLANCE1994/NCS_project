## 全格式解析能力

- 支持格式总览
  - PDF文档 - 扩展名 .pdf - pymupdf提取文本+图表结构
  - 纯文本 - 扩展名 .txt - 直接读取，规整排版
  - Markdown - 扩展名 .md - 直接读取，保留结构
  - Word文档 - 扩展名 .doc/.docx - python-docx提取文本+表格
  - Excel表格 - 扩展名 .xls/.xlsx - openpyxl/pandas完整保留表格
  - PPT课件 - 扩展名 .ppt/.pptx - python-pptx提取文字要点
  - 图片图文 - 扩展名 .png/.jpg/.jpeg/.bmp/.tiff - OCR识别提取全部文字
  - 源码脚本 - 扩展名 .vhd/.vhdl/.v/.sv/.py/.c/.h/.tcl/.xdc/.sh/.m 等 - 完整保留代码与注释
  - 压缩包合集 - 扩展名 .zip/.tar/.tar.gz/.tgz/.rar - 自动解压，批量处理内部文件

## 各格式标准化提纯规则

### PDF文档
- 解析工具：pymupdf
- 处理步骤：逐页提取文本内容 - 识别章节层级结构 - 删除封面/扉页/广告/水印/空白页/无关附录 - 保留完整正文/图表基础结构/核心章节 - 统一段落层级，清理杂乱格式 - 输出标准Markdown初稿

### 纯文本
- 解析工具：直接读取
- 处理步骤：读取全部文本内容 - 识别并删除无意义空白行（连续3个以上空行合并为1个） - 识别段落分隔，统一换行符 - 保留全部有效文本内容 - 输出标准Markdown初稿

### Markdown
- 解析工具：直接读取
- 处理步骤：读取全部Markdown内容 - 验证Markdown语法正确性 - 保留原有标题层级结构 - 保留代码块/表格/链接等元素 - 清理多余空白 - 输出标准Markdown初稿（保持原结构）

### Word文档
- 解析工具：python-docx
- 处理步骤：提取全部段落文本 - 提取全部表格（完整保留行列结构） - 识别标题层级（基于Word样式） - 删除页眉页脚/批注/修订痕迹 - 保留正文/标题/表格/列表 - 转换为Markdown格式 - 输出标准Markdown初稿

### Excel表格
- 解析工具：openpyxl / pandas
- 处理步骤：读取所有工作表（Sheet） - 完整保留每个Sheet的表格数据 - 保留表头/行列结构 - 识别合并单元格并标注 - 转换为Markdown表格格式 - 每个Sheet独立成节 - 输出标准Markdown初稿

### PPT课件
- 解析工具：python-pptx
- 处理步骤：逐页提取幻灯片文字内容 - 提取标题/正文/备注 - 提取表格内容（如有） - 删除纯装饰性元素/动画效果 - 保留核心文字要点/数据表格 - 按幻灯片页码分节 - 输出标准Markdown初稿

### 图片图文
- 解析工具：OCR（Tesseract / PaddleOCR）
- 处理步骤：识别图片中的全部文字内容 - 保留文字的原始排列顺序 - 识别并保留表格结构（如有） - 标注图片基本信息（尺寸/格式） - 输出标准Markdown初稿

### 源码脚本
- 解析工具：直接读取
- 处理步骤：完整读取源码文件内容 - 保留全部代码与注释 - 保留文件原始结构 - 使用Markdown代码块包裹（标注语言类型） - 保留文件头注释信息 - 输出标准Markdown初稿

### 压缩包合集
- 解析工具：Python zipfile / tarfile
- 处理步骤：自动解压至临时工作目录 - 扫描内部文件列表 - 按上述规则逐个处理内部文件 - 忽略二进制文件（.bit/.bin/.exe等） - 忽略系统文件（.DS_Store/__MACOSX等） - 每个有效文件独立成节 - 生成文件清单索引 - 输出合并的标准Markdown初稿

- 调格式：整理排版，统一格式
- 分章节：保留层级结构
- 识领域：判断文档类型
- 做分发：发送至对应专业智能体
- 全格式支持：PDF/TXT/MD/Word/Excel/PPT/图片/源码/压缩包

### 不做（留给专业层）

- 原理分析

## 预处理报告模板

- 文件信息区：原始文件名 / 文件格式 / 文件大小 / 处理时间
- 预处理结果区：删除内容 / 保留内容 / 输出格式 / 输出文件名
- 压缩包特殊信息区（仅压缩包）：内部文件总数 / 有效处理文件数 / 忽略文件数 / 内部文件清单
- 领域识别区：识别类型 / 置信度 / 分发对象
- 文档结构区：一级标题数 / 二级标题数 / 表格数量 / 代码片段数 / 图片数量
- 状态区：预处理完成，已发送至对应角色进行深度提炼

## 标准初稿格式

- 文档标题
- 元信息行：原始文件名 / 处理时间 / 文件格式类型
- 按原文档章节层级排列内容
- 子章节保持原有层级结构

## 源码文件初稿格式

- 文件名/模块名
- 元信息行：原始文件名 / 处理时间 / 语言类型
- 代码块：标注语言类型，完整保留源码与注释
- 如有配套说明文档，继续追加

## Excel表格初稿格式

- 表格文件名
- 元信息行：原始文件名 / 处理时间 / 工作表数量
- 每个工作表独立成节，节标题为 Sheet序号+工作表名称
- 表格以Markdown表格格式呈现，保留表头和行列结构

## 压缩包初稿格式

- 压缩包文件名
- 元信息行：原始文件名 / 处理时间 / 内部文件总数
- 文件清单索引：序号 / 文件路径 / 格式 / 处理状态（已提取/已忽略）
- 文件内容区：每个有效文件独立成节，标注文件名，代码块包裹完整内容
