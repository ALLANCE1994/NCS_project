> **版本**：V1.0

> **维护人**：文档预处理工程师

---

## 一、总则

### 1.1 目标

将所有格式的项目资料文件，通过标准化提纯流程，统一转换为结构清晰的Markdown初稿，供后续专业智能体深度提炼。

### 1.2 核心原则

1. **格式无关性**：所有格式最终统一输出为Markdown
2. **内容保真性**：提取过程中不丢失、不篡改原文内容
3. **结构保留性**：保留原文档的章节层级和逻辑结构
4. **零解读原则**：仅做格式转换和清洗，不做任何专业技术解读
5. **本地存档优先**：所有资料默认仅本地存档，不自动向量入库

### 1.3 支持格式矩阵

| 格式类别 | 支持格式 | 扩展名 | 解析工具 | 输出方式 |
|----------|----------|--------|----------|----------|
| PDF文档 | PDF | `.pdf` | pymupdf | 文本提取+结构保留 |
| 纯文本 | TXT | `.txt` | 直接读取 | 规整排版 |
| Markdown | MD | `.md` | 直接读取 | 结构保留 |
| Word文档 | Word | `.doc`, `.docx` | python-docx | 文本+表格提取 |
| Excel表格 | Excel | `.xls`, `.xlsx` | openpyxl | 表格完整保留 |
| PPT课件 | PowerPoint | `.ppt`, `.pptx` | python-pptx | 文字要点提取 |
| 图片图文 | 图片 | `.png`, `.jpg`, `.jpeg`, `.bmp`, `.tiff` | OCR | 文字识别提取 |
| 源码脚本 | 各类代码 | `.vhd`, `.vhdl`, `.v`, `.sv`, `.py`, `.c`, `.h`, `.tcl`, `.xdc`, `.sh`, `.m` 等 | 直接读取 | 代码+注释完整保留 |
| 压缩包合集 | 压缩包 | `.zip`, `.tar`, `.tar.gz`, `.tgz`, `.rar` | zipfile/tarfile | 解压后批量处理 |

## 二、各格式提纯详细规范

### 2.1 PDF文档

#### 解析流程
```
PDF文件 → pymupdf读取 → 逐页提取文本 → 识别章节层级 → 删除冗余 → 输出Markdown
```

#### 处理规则
| 操作 | 规则 |
|------|------|
| **删除** | 封面、扉页、目录页（自动生成部分）、广告页、水印文字、空白页、无关附录 |
| **保留** | 完整正文、标题层级、图表基础结构、公式文本、表格数据、脚注 |
| **转换** | PDF标题样式 → Markdown标题（#、##、###） |

#### 输出模板
```markdown
# [文档标题]

> 原始文件：XXX.pdf
> 处理时间：YYYY-MM-DD HH:MM

---

## [一级标题]
[正文内容...]

### [二级标题]
[正文内容...]

#### [三级标题]
[正文内容...]

| 表头1 | 表头2 |
|-------|-------|
| 数据1 | 数据2 |
```

---

### 2.2 纯文本（TXT）

#### 解析流程
```
TXT文件 → 直接读取 → 合并多余空行 → 统一换行符 → 识别段落 → 输出Markdown
```

#### 处理规则
| 操作 | 规则 |
|------|------|
| **删除** | 连续3个以上空行（合并为1个） |
| **保留** | 全部有效文本内容 |
| **转换** | 识别段落分隔，添加适当空行 |

#### 输出模板
```markdown
# [文件名]

> 原始文件：XXX.txt
> 处理时间：YYYY-MM-DD HH:MM

---

[文本内容，段落间空一行]
```

---

### 2.3 Markdown（MD）

#### 解析流程
```
MD文件 → 直接读取 → 验证语法 → 清理空白 → 输出Markdown
```

#### 处理规则
| 操作 | 规则 |
|------|------|
| **删除** | 多余尾部空白 |
| **保留** | 全部Markdown元素（标题、代码块、表格、链接、图片引用） |
| **转换** | 无需转换，保持原结构 |

#### 输出模板
```markdown
# [文件名]

> 原始文件：XXX.md
> 处理时间：YYYY-MM-DD HH:MM

---

[原始Markdown内容，保持原结构]
```

---

### 2.4 Word文档（DOC/DOCX）

#### 解析流程
```
Word文件 → python-docx读取 → 提取段落+表格 → 识别标题层级 → 删除冗余 → 输出Markdown
```

#### 处理规则
| 操作 | 规则 |
|------|------|
| **删除** | 页眉页脚、批注、修订痕迹、嵌入对象（OLE） |
| **保留** | 正文段落、标题（Heading 1-6）、表格（完整行列）、列表（有序/无序）、图片描述文字 |
| **转换** | Word标题样式 → Markdown标题；Word表格 → Markdown表格；Word列表 → Markdown列表 |

#### 输出模板
```markdown
# [文档标题]

> 原始文件：XXX.docx
> 处理时间：YYYY-MM-DD HH:MM

---

## [一级标题]
[正文内容...]

### [二级标题]
[正文内容...]

| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 数据 | 数据 | 数据 |

- 列表项1
- 列表项2
```

---

### 2.5 Excel表格（XLS/XLSX）

#### 解析流程
```
Excel文件 → openpyxl读取 → 遍历所有Sheet → 提取表格数据 → 输出Markdown
```

#### 处理规则
| 操作 | 规则 |
|------|------|
| **删除** | 空Sheet、完全空白的行列 |
| **保留** | 所有有效Sheet的全部数据、表头、合并单元格信息 |
| **转换** | 每个Sheet独立成Markdown节；Excel表格 → Markdown表格 |

#### 输出模板
```markdown
# [文件名]

> 原始文件：XXX.xlsx
> 处理时间：YYYY-MM-DD HH:MM
> 工作表数量：X个

---

## Sheet 1: [工作表名称]

| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 数据 | 数据 | 数据 |

## Sheet 2: [工作表名称]

| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 数据 | 数据 | 数据 |
```

---

### 2.6 PPT课件（PPT/PPTX）

#### 解析流程
```
PPT文件 → python-pptx读取 → 逐页提取 → 提取文字+表格 → 输出Markdown
```

#### 处理规则
| 操作 | 规则 |
|------|------|
| **删除** | 纯装饰性图形、动画效果描述、嵌入媒体文件 |
| **保留** | 每页标题、正文文字、备注内容、表格数据 |
| **转换** | 每页幻灯片 → 独立Markdown节；幻灯片内文字层级 → Markdown列表 |

#### 输出模板
```markdown
# [演示文稿标题]

> 原始文件：XXX.pptx
> 处理时间：YYYY-MM-DD HH:MM
> 幻灯片总数：X页

---

## 第1页：[幻灯片标题]

[正文内容，按层级列出]

## 第2页：[幻灯片标题]

[正文内容]

| 列1 | 列2 |
|-----|-----|
| 数据 | 数据 |
```

---

### 2.7 图片图文（PNG/JPG/JPEG/BMP/TIFF）

#### 解析流程
```
图片文件 → OCR识别 → 提取文字 → 识别表格结构 → 输出Markdown
```

#### 处理规则
| 操作 | 规则 |
|------|------|
| **删除** | 无文字的纯装饰性图片内容 |
| **保留** | OCR识别的全部文字内容、识别到的表格结构 |
| **转换** | OCR文字 → Markdown文本；识别表格 → Markdown表格 |

#### 输出模板
```markdown
# [图片文件名]

> 原始文件：XXX.png
> 处理时间：YYYY-MM-DD HH:MM
> 图片尺寸：XXXX x XXXX
> OCR引擎：[Tesseract/PaddleOCR]

---

[OCR识别的全部文字内容]

| 列1 | 列2 |（如有表格）
|-----|-----|
| 数据 | 数据 |
```

---

### 2.8 源码脚本（各类代码文件）

#### 解析流程
```
源码文件 → 直接读取 → 完整保留 → 代码块包裹 → 输出Markdown
```

#### 处理规则
| 操作 | 规则 |
|------|------|
| **删除** | 无 |
| **保留** | 全部源码内容、全部注释、文件头信息 |
| **转换** | 源码 → Markdown代码块（标注语言类型） |

#### 语言类型标注映射

| 扩展名 | 语言标注 | 扩展名 | 语言标注 |
|--------|----------|--------|----------|
| `.vhd`, `.vhdl` | vhdl | `.py` | python |
| `.v`, `.sv` | verilog | `.c` | c |
| `.tcl` | tcl | `.h` | c |
| `.xdc` | tcl | `.m` | matlab |
| `.sh` | bash | `.js` | javascript |

#### 输出模板
```markdown
# [文件名/模块名]

> 原始文件：XXX.vhd
> 处理时间：YYYY-MM-DD HH:MM
> 语言类型：VHDL

---

```vhdl
-- 完整源码内容
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;
...
```
```

### 2.9 压缩包合集（ZIP/TAR/TAR.GZ/TGZ/RAR）

#### 解析流程
```
压缩包 → 自动解压 → 扫描文件列表 → 分类处理 → 合并输出Markdown
```

#### 处理规则
| 操作 | 规则 |
|------|------|
| **忽略** | 二进制文件（`.bit`, `.bin`, `.exe`, `.dll`, `.so`等）、系统文件（`.DS_Store`, `__MACOSX`, `.git`等）、空文件 |
| **处理** | 所有文本类文件按上述对应格式规则处理 |
| **转换** | 每个有效文件独立成节，生成文件清单索引 |

#### 内部文件分类处理

| 文件类型 | 处理方式 |
|----------|----------|
| PDF | 按2.1规则处理 |
| Word | 按2.4规则处理 |
| Excel | 按2.5规则处理 |
| PPT | 按2.6规则处理 |
| 图片 | 按2.7规则处理 |
| 源码 | 按2.8规则处理 |
| TXT/MD | 按2.2/2.3规则处理 |
| 二进制 | 忽略，仅记录文件名 |

#### 输出模板
```markdown
# [压缩包文件名]

> 原始文件：XXX.zip
> 处理时间：YYYY-MM-DD HH:MM
> 内部文件总数：X个
> 有效处理文件数：X个

## 三、通用清洗规则

### 3.1 所有格式通用删除项

| 删除项 | 说明 |
|--------|------|
| 连续空行 | 3个及以上空行合并为1个 |
| 尾部空白 | 删除文件末尾多余空白 |
| 不可见字符 | 删除零宽字符、控制字符等 |
| 重复内容 | 压缩包中重复文件仅保留一份 |

### 3.2 所有格式通用保留项

| 保留项 | 说明 |
|--------|------|
| 有效文本 | 全部有效文字内容 |
| 表格数据 | 完整的行列结构 |
| 代码内容 | 完整的源码和注释 |
| 层级结构 | 原文档的章节/段落层级 |
| 元数据 | 文件名、格式、处理时间 |

## 四、异常处理

### 4.1 格式异常

| 异常情况 | 处理方式 |
|----------|----------|
| 文件损坏无法读取 | 报告错误，跳过该文件 |
| 格式识别失败 | 尝试按纯文本处理 |
| 编码异常 | 尝试UTF-8、GBK、Latin-1等编码 |
| OCR识别率低 | 标注低置信度，建议人工复核 |
| 压缩包密码保护 | 报告错误，请求用户提供密码 |

### 4.2 内容异常

| 异常情况 | 处理方式 |
|----------|----------|
| 文件内容为空 | 记录并跳过 |
| 提取内容过少 | 标注警告，继续处理 |
| 表格结构异常 | 尽量保留原始数据，标注异常 |
