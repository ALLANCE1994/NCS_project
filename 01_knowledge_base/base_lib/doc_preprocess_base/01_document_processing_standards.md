# 通用文档处理标准

> **适用角色**：文档预处理工程师  
> **知识类型**：通用基础能力  
> **更新日期**：2026-05-16

---

## 一、文档处理核心原则

### 1.1 分层处理理念

文档处理遵循**「粗加工 + 精提炼」**的双层模式：

| 层级 | 执行者 | 职责 | 输出 |
|------|--------|------|------|
| 第一层 | 文档预处理工程师 | 格式清洗、结构整理 | 标准初稿 |
| 第二层 | 专业智能体 | 内容提炼、知识萃取 | 干货文档 |

### 1.2 处理边界

**只做**：
- ✅ 文档格式标准化
- ✅ 内容结构梳理
- ✅ 冗余信息清理
- ✅ 分类归档整理

**不做**：
- ❌ 技术内容解读
- ❌ 专业知识总结
- ❌ 业务逻辑分析
- ❌ 经验方法提炼

## 二、PDF文档解析规范

### 2.1 解析前检查

- [ ] 文件完整性检查（是否损坏、加密）
- [ ] 文件格式确认（PDF版本兼容性）
- [ ] 内容可读性验证（文本层是否存在）
- [ ] 扫描件识别（OCR需求评估）

### 2.2 内容提取标准

#### 文本提取
```
提取优先级：
1. 正文段落（最高优先级）
2. 标题层级（H1-H6对应关系）
3. 列表内容（有序/无序列表）
4. 表格数据（行列对应关系）
5. 代码块（格式保留）
```

#### 图像处理
```
处理方式：
- 图表：保留并标注位置
- 插图：视相关性决定是否保留
- 水印：识别并删除
- 扫描痕迹：清理优化
```

### 2.3 页面筛选规则

| 页面类型 | 处理方式 | 说明 |
|----------|----------|------|
| 封面 | 删除 | 仅保留标题信息到元数据 |
| 扉页/版权页 | 删除 | 记录版权信息 |
| 目录 | 保留结构 | 转换为Markdown目录 |
| 正文 | 完整保留 | 核心处理对象 |
| 附录 | 选择性保留 | 根据相关性判断 |
| 广告/宣传页 | 删除 | 无关内容 |
| 空白页 | 删除 | 无信息价值 |

## 三、文本清洗通用规则

### 3.1 格式标准化

#### 编码统一
- 统一使用UTF-8编码
- 处理特殊字符转义
- 统一换行符格式（LF）

#### 空白处理
```
规则：
- 删除行首行尾多余空格
- 合并连续空行（最多保留1行）
- 删除段落内多余空格
- 保留代码块内格式
```

#### 标点规范
```
统一标准：
- 中文内容使用中文标点
- 英文内容使用英文标点
- 混合内容以主要语言为准
- 特殊符号统一转义表示
```

### 3.2 内容清理

#### 删除内容清单
- [ ] 页眉页脚信息
- [ ] 页码标记
- [ ] 文档属性水印
- [ ] 批注和修订标记
- [ ] 超链接（保留文本）
- [ ] 隐藏文字

#### 保留内容清单
- [ ] 正文核心内容
- [ ] 层级标题结构
- [ ] 关键图表说明
- [ ] 代码和公式
- [ ] 参考文献列表

## 四、多格式文稿统一排版准则

### 4.1 Markdown格式规范

#### 标题层级
```markdown
# 一级标题（文档标题，唯一）
## 二级标题（主要章节）
### 三级标题（小节）
#### 四级标题（细分内容）
##### 五级标题（少用）
###### 六级标题（极少用）
```

#### 段落格式
```markdown
- 段落间空一行
- 首行不缩进
- 长段落适当分段
- 重点内容使用加粗
```

#### 列表规范
```markdown
无序列表：
- 项目一
- 项目二
  - 子项目
  - 子项目

有序列表：
1. 第一步
2. 第二步
3. 第三步
```

### 4.2 表格统一格式

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 内容 | 内容 | 内容 |
| 内容 | 内容 | 内容 |
```

### 4.3 代码块规范

```markdown
```python
# 代码注释
代码内容
```

```vhdl
-- 代码注释
代码内容
```
```

## 五、文件分类归档通用逻辑

### 5.1 分类维度

| 维度 | 分类标准 | 示例 |
|------|----------|------|
| 文档类型 | 技术/管理/规范 | 设计文档、项目计划、质量标准 |
| 专业领域 | 学科/技术方向 | 量子物理、FPGA、软件工程 |
| 内容深度 | 基础/进阶/专家 | 入门指南、技术手册、研究论文 |
| 来源性质 | 内部/外部/标准 | 内部文档、厂商资料、行业标准 |

### 5.2 命名规范

```
格式：[日期]_[来源]_[主题]_[版本].md

示例：
20260516_Xilinx_ZYNQ基础指南_v1.0.md
20260516_内部_项目计划模板_v2.0.md
```

## 六、文档流转基础流程

### 6.1 标准流转路径

```
接收文档
    │
    ▼
格式检查 → 完整性验证
    │
    ▼
内容提取 → 结构解析
    │
    ▼
清洗整理 → 格式标准化
    │
    ▼
分类归档 → 元数据标注
    │
    ▼
生成初稿 → 质量检查
    │
    ▼
分发专业智能体
```

### 6.2 质量检查清单

- [ ] 文档结构完整
- [ ] 格式规范统一
- [ ] 内容无缺失
- [ ] 分类准确
- [ ] 元数据完整
- [ ] 可正常读取

### 6.3 异常处理

| 异常情况 | 处理方式 |
|----------|----------|
| 文件损坏 | 记录并上报 |
| 内容加密 | 申请解密权限 |
| 格式混乱 | 标记待人工处理 |
| 分类不明 | 标记待确认 |
