# 技能：保存工作进度

## 技能元数据
- 技能ID：save-work-progress
- 版本：1.0.0
- 描述：保存当前工作进度，执行代码归档+Git提交+工作记录
- 适用场景：每次工作结束前、任务完成后、阶段转换前
- 绑定智能体：全体智能体（各自保存各自产出）

## 输入参数
- agent：当前智能体编号
- changed_files：本次修改的文件列表
- commit_msg：提交描述
- need_report：是否需要工作记录报告，默认简单任务否

## 执行逻辑
1. 确认文件保存路径符合规范（VHDL→01_vhdl_modules/、Python→02_python_drivers/等）
2. 执行Git提交：git add . && git commit -m "[@X] 描述" && git push
3. 如 need_report=是，生成工作记录到 04_docs/02_reports/YYYYMMDD_内容.md
4. 输出保存确认

## 输出要求
- 保存确认：列出已保存的文件（格式：- 文件名 — 简要修改说明）
- Git提交结果：提交哈希/成功/失败

## 示例调用
调用技能：保存工作进度
- agent: @H
- changed_files: dds_controller.vhd, dds_controller_tb.vhd
- commit_msg: 添加DDS相位累加器端口定义和测试激励
- need_report: 否
