# 技能：文档预处理与分发

## 技能元数据
- 技能ID：doc-preprocess-dispatch
- 版本：1.0.0
- 描述：接收任意格式文件，执行粗加工（格式清洗+Markdown初稿+领域识别+精准分发）
- 适用场景：客户上传文档、知识库投喂、外部资料整理
- 绑定智能体：@D 文档预处理工程师

## 输入参数
- input_file：输入文件路径
- output_dir：输出目录，默认 01_knowledge_base/
- auto_dispatch：是否自动分发，默认是

## 执行逻辑
1. 识别文件格式（PDF/TXT/MD/Word/Excel/PPT/图片/源码/压缩包）
2. 执行格式清洗：删除封面/广告/水印/空白页，保留正文/表格/代码/章节结构
3. 输出标准Markdown初稿（XXX_preprocessed.md）
4. 领域识别：量子→@Q、硬件→@H、软件→@S、架构→@P、规范→@V、AI→@A、文档→@E
5. 如 auto_dispatch=是，生成分发指令

## 输出要求
- 预处理报告：文件格式、页数/行数、清洗操作、领域识别结果
- Markdown初稿：保存至 output_dir
- 分发指令：@专业智能体 请基于预处理初稿进行深度提炼

## 示例调用
调用技能：文档预处理与分发
- input_file: uploads/nv_odmr_paper.pdf
- output_dir: 01_knowledge_base/
- auto_dispatch: 是
