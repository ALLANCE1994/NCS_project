# 技能：检查规则合规

## 技能元数据
- 技能ID：check-rule-compliance
- 版本：1.0.0
- 描述：对指定交付物执行分层合规检查，判定通过/不通过/有条件通过
- 适用场景：任务完成后、阶段转换前、交付物验收时
- 绑定智能体：@V 工程规则管理师

## 输入参数
- target：检查对象（文件路径或交付物描述）
- depth：检查深度（轻量/常规/深度），默认根据任务类型自动判定
- requester：提交检查的智能体编号

## 执行逻辑
1. 判定任务类型：简单任务→轻量，标准任务→常规，关键任务→深度
2. 按深度执行检查维度：
   - 轻量：P0规则5项 + 角色职责
   - 常规：+ P1规则4项 + 输出标准
   - 深度：+ 项目灵魂4项 + Vivado完整性
3. 逐项判定：通过/不通过/有条件通过
4. 汇总输出检查结论

## 输出要求
- 通过：一句话输出 ✅ [对象] 审核通过：[一句话结论]
- 不通过：输出不合规项清单 + 整改要求 + 严重程度标注
- 有条件通过：输出条件项 + 整改建议

## 示例调用
调用技能：检查规则合规
- target: 03_code/01_vhdl_modules/dds_controller.vhd
- depth: 常规
- requester: @H
