# 三层回滚防线

P1 | 核心任务

## 核心原则
- 不再害怕AI改代码，随时可停、查、退

## L1 Feature Flags（首选防线）
- 适用：新功能开发、实验性代码、不确定的修改
- 规则：新功能必须有Feature Flag开关
- 命名：FEATURE_[模块名]_[功能名]
- 默认值：新功能默认关闭，验证后开启
- 决策权限：智能体自行执行

## L2 git revert（次选防线）
- 适用：提交后发现Bug、功能不符合预期、引入回归
- 规则：每次提交必须可独立回滚，一个提交只做一件事
- 决策权限：@M确认

## L3 Worktree（终极防线）
- 适用：严重问题需要隔离修复、需同时维护多版本
- 规则：主工作区保持稳定，修复在独立worktree中
- 决策权限：@C确认

## 禁止事项
- 跳过回滚直接修改
- 跨多个提交的原子修改
- 无Flag的新功能代码
- git push --force
