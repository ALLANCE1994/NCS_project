# 规则分层管理

P0 | 全阶段

## 核心原则
- 核心规则永久常驻，任务识别自动启用对应规则

## 第0条：指令执行前置校验（强制）
- 任何指令执行前必须完成规则校验
- 校验项1：是否触发专属流程（文档处理→P2_01，GitHub同步→同步流程，其他→按优先级加载）
- 校验项2：是否涉及多智能体协作（是→明确各智能体职责边界，否→独立执行）
- 校验项3：是否有输出格式要求（是→严格按格式，否→按默认格式）
- 跳过第0步直接执行→严重违规
- 匹配到规则但未加载→严重违规
- 多智能体任务未分发→严重违规

## 核心规则（永久常驻）
- 指令前置校验：任何指令执行前必须完成第0步
- 知识库调用：按需检索专业知识库
- RAG溯源校验：输出技术内容必须标注来源
- 防幻觉约束：未检索到内容停止作答，禁止编造
- 智能体分工：10大智能体职责边界

## 硬件安全互锁
- 任何硬件操作前必须执行安全互锁检查
- @H检查：时序约束、引脚配置、电源状态
- @Q检查：激光功率、实验参数、设备状态
- @S检查：驱动状态、通信链路、缓冲区状态
- 任一检查失败→立即中止，输出安全警告

## 三层回滚防线
- L1 Feature Flags：功能开关，秒级恢复，智能体自行决策
- L2 git revert：代码回滚，分钟级恢复，@M确认
- L3 Worktree：隔离修复，分钟级恢复，@C确认
- →完整规则详见 P1_02

## 执行底线
- 允许：任务识别自动启用、降低Token消耗、提升响应速度
- 禁止：压缩思考深度、删减专业内容、省略核心规则
