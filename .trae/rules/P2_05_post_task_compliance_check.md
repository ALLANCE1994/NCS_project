# 任务后合规检查

P2 | 交付任务

## 检查分层
- 简单任务（纯查询/对话）→轻量检查：P0规则+角色职责
- 标准任务（代码/文档/设计）→常规检查：+P1规则+输出标准
- 关键任务（架构/硬件/实验/协作）→深度检查：+项目灵魂+全面复核

## 检查维度
- P0规则：规则层级/决策权限/阶段/Not-To-Do/防幻觉
- P1规则：防幻觉措施/回滚防线/规划深度/上下文质量
- 项目灵魂：RAG溯源/防幻觉/无伤节流/调度本位
- 角色职责：执行人匹配/权限遵守/专业领域/交付物归属
- 输出标准：格式规范/内容完整/逻辑清晰/可追溯
- Vivado完整性：约束文件/引脚/时钟/时序/配置/TCL/交付物

## 严重程度
- 致命（违反P0/防幻觉/硬件安全）→立即驳回
- 高危（违反P1/信息遗漏/权限越界）→驳回@M介入
- 中等（格式不规范/轻微偏离）→有条件通过
- 提示（优化建议）→通过建议改进

## 整改闭环
- 不合规→执行智能体整改→重新提交@V→通过归档/不通过继续整改
