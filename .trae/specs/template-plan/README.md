# Plan 工作流模板使用说明

## 模板文件

| 文件 | 用途 | 调用时机 |
|------|------|----------|
| plan.md | 执行计划模板 | 中小型模块任务 |

## 使用流程

### 1. 新建任务目录

```
.trae/specs/YYYYMMDD_任务名称_Plan/
└── plan.md
```

### 2. 调用方式

- MTC 输入框输入 `/` 选择「Plan」
- 或直接输入：`/plan 任务描述`

### 3. 文档填写

1. 填写任务概述（目标、范围、预期产出）
2. 拆解执行步骤（每个步骤明确执行人、操作内容、验收标准）
3. 识别风险与应对措施
4. 确认资源需求

## 命名约束

- 任务目录：`YYYYMMDD_任务名称_Plan`
- 文件名：固定为 `plan.md`
- 任务名称：小写字母+数字+下划线，≤20字

## 状态符号

- ⏳ 待执行
- 🔄 执行中
- ✅ 已完成
- ⬜ 未就绪

## Spec vs Plan 选择

| 工作流 | 适用场景 | 文件数量 |
|--------|----------|----------|
| Spec | 复杂系统级任务、多模块协作、需要完整需求分析 | 3个（spec/tasks/checklist） |
| Plan | 中小型模块任务、单智能体可完成、步骤清晰 | 1个（plan） |

## 注意事项

- 不直接修改模板文件
- 新建任务时复制模板内容
- 所有文档纳入 Git 版本控制
