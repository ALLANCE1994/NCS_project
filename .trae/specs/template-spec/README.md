# Spec 工作流模板使用说明

## 模板文件

| 文件 | 用途 | 调用时机 |
|------|------|----------|
| spec.md | 需求大纲模板 | 复杂系统级任务启动时 |
| tasks.md | 任务拆解模板 | spec.md 确认后 |
| checklist.md | 验收清单模板 | 任务执行完成后 |

## 使用流程

### 1. 新建任务目录

```
.trae/specs/YYYYMMDD_任务名称_Spec/
├── spec.md
├── tasks.md
└── checklist.md
```

### 2. 调用方式

- MTC 输入框输入 `/` 选择「Spec」
- 或直接输入：`/spec 任务描述`

### 3. 文档填写顺序

1. **spec.md**：填写背景、目标、需求、技术方案
2. **tasks.md**：拆解任务、分配负责人、定义依赖
3. **checklist.md**：执行完成后逐项验收

## 命名约束

- 任务目录：`YYYYMMDD_任务名称_Spec`
- 文件名：固定为 `spec.md` / `tasks.md` / `checklist.md`
- 任务名称：小写字母+数字+下划线，≤20字

## 状态符号

- ⏳ 待启动
- 🔄 进行中
- ✅ 已完成
- ❌ 阻塞
- ⬜ 未验收

## 注意事项

- 不直接修改模板文件
- 新建任务时复制模板内容
- 所有文档纳入 Git 版本控制
