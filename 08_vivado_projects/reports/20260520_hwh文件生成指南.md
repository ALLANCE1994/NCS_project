# NV工程 - .hwh文件生成指南

**日期**: 2026-05-20
**问题**: 缺少PYNQ Overlay必需的.hwh硬件设计文件

---

## 问题说明

`.hwh`文件是Vivado生成的硬件设计文件，包含：
- 硬件模块层次结构
- IP核配置信息
- 地址映射信息
- 是PYNQ Overlay生成的必要输入

**当前状态**: Bitstream已生成，但.hwh文件缺失

---

## 解决方案

### 方法1：运行更新后的TCL脚本（推荐）

```bash
# 进入Vivado工程目录
cd 08_vivado_projects/odmr_zynq7020

# 运行Bitstream生成脚本（已包含.hwh导出）
vivado -mode batch -source ../scripts/04_run_bitstream.tcl

# 或单独导出.hwh
vivado -mode batch -source {your_project}.xpr -tclargs {your_project}
# 在Vivado TCL Console中执行：
open_run impl_1
write_hw_def -file odmr_zynq7020.runs/impl_1/odmr_zynq7020.hwh
```

### 方法2：Vivado GUI导出

1. 打开Vivado工程 `odmr_zynq7020.xpr`
2. 打开综合后的设计：`Flow → Open Run → impl_1`
3. 导出硬件设计：`File → Export → Export Hardware`
4. 选择"Include bitstream"和"Export .hwh"
