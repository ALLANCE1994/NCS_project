# 全员无伤节流规则

> **文档编号**：NV-FPGA-THROTTLE-001
> **版本**：V1.0
> **生效日期**：2026-05-16
> **适用范围**：全体10大智能体
> **优先级**：与防幻觉铁律同级，全员强制遵守

---

## 核心原则

**剔除无效冗余，保障核心质量。节流的是废话，不是干货。**

---

## 一、输出精简规则

### 1.1 必须剔除的内容

| 剔除项 | 示例 |
|--------|------|
| 客套话 | "非常感谢您的提问"、"好的，我来帮您处理" |
| 多余铺垫 | "接下来我将为您..."、"首先让我们了解一下..." |
| 重复话术 | 已说过的话不再换种说法再说一遍 |
| 无效修饰 | "非常重要的"、"非常关键的"、"值得一提的是" |
| 冗余总结 | 结尾重复正文已说过的内容 |

### 1.2 必须完整保留的内容（红线，绝不删减）

| 保留项 | 说明 |
|--------|------|
| 专业原理 | 物理公式、推导过程、技术原理 |
| 参数数据 | 实验参数、硬件参数、配置数值 |
| 代码内容 | 完整代码、必要注释 |
| 溯源依据 | RAG知识来源标注 |
| 审核流程 | 检查项、审核标准、问题清单 |
| 逻辑推理 | 分析过程、判断依据、决策逻辑 |

### 1.3 严禁的伤质量行为

| 禁止行为 | 说明 |
|----------|------|
| ❌ 缩减逻辑推理过程 | 分析必须完整，不能跳步 |
| ❌ 精简必要代码注释 | 关键注释必须保留 |
| ❌ 省略实验关键参数 | 参数不能遗漏 |
| ❌ 取消RAG来源标注 | 溯源标注不可省略 |
| ❌ 简化内容核验流程 | 审核步骤不可压缩 |
| ❌ 强行压缩输出篇幅 | 该长则长，不为短而短 |

---

## 二、任务执行规则

### 2.1 一事一议

- 单次对话只处理**单一类别**工作
- 不混合多项大型任务
- 避免上下文冗余臃肿

### 2.2 按需加载

- 仅调用当前任务**必需**的知识库内容
- 不批量全量读取所有知识库文件
- 减少无效输入消耗

### 2.3 分批处理

- 长篇资料分批次处理
- 大批量文件分批次处理
- 不一次性集中处理海量内容

---

## 三、流程复述规则

### 3.1 不主动复述

- 固定流程、固定规则**不再每次完整复述**
- 仅在客户主动询问时完整说明
- 日常执行直接按规则操作，不解释规则本身

### 3.2 复述触发条件

仅在以下情况完整说明流程/规则：
- 客户主动询问
- 客户输入 `启动NV项目`（按接续文案输出）
- 首次执行某类任务时（仅首次）
