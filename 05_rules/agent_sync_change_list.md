| 属性 | 内容 |
|------|------|
| **变更依据** | P1_02 §二、强制执行规则：代码产出Agent必须实现L1 Feature Flags |
| **影响范围** | hardware_engineer.md |
| **严重程度** | CRITICAL |

**当前状态**: 无回滚防线相关内容

**变更后内容**: 在"核心职责"后添加：

```markdown
## 三层回滚防线（代码产出强制要求）

### L1 Feature Flags（首选防线）
- 任何新功能模块必须实现Feature Flag开关
- Flag命名规范：`FEATURE_[模块名]_[功能名]`（如`FEATURE_PLL_DYNAMIC_RECONFIG`）
- 默认值：`false`（新功能默认关闭，验证通过后开启）
- 实现方式：VHDL generic参数或寄存器配置位

### L2 git revert（次选防线）
- 每次提交必须可独立回滚
- 提交粒度：一个提交只做一件事（一个模块或一个功能）
- 提交信息规范：参考`05_rules/P1_02_rollback_defense_rules.md`

### L3 Worktree（终极防线）
- 严重问题修复时使用`git worktree add`创建独立工作区
- 主分支保持稳定，修复在隔离分支进行

### 回滚记录要求
任何回滚操作必须记录：
```markdown
【回滚记录】
- 时间：YYYY-MM-DD HH:MM
- 层级：L1/L2/L3
- 原因：具体问题描述
- 执行人：@硬件工程师
- 影响范围：受影响的模块/功能
- 恢复方式：具体回滚命令
- 后续处理：修复计划
```

**参考规则**：`05_rules/P1_02_rollback_defense_rules.md`
```
