## 使用说明

### 清单结构说明

| 字段 | 含义 |
|------|------|
| **资料名称** | 需要搜集的具体资料/文档名称 |
| **用途作用** | 该资料在项目中的具体作用和解决什么问题 |
| **资料类型** | 通用行业标准资料 / 芯片工具官方手册 / 本项目专属定制资料 / 故障排查与实战案例 |
| **获取/查找方向** | 从哪里可以找到这份资料 |
| **优先级** | ★★★ 核心优先（首批搜集）/ ★★☆ 后期补充（进阶资料） |

### 四大资料类型定义

| 类型编号 | 类型名称 | 说明 |
|:--------:|----------|------|
| A | 通用行业标准资料 | 行业通用规范、标准协议、通用设计准则 |
| B | 芯片/工具官方手册 | Xilinx/AMD官方文档、PYNQ官方文档、工具链手册 |
| C | 本项目专属定制资料 | 本项目原理图、PCB、BOM、实验方案、接口定义等 |
| D | 故障排查与实战案例 | 调试经验、常见错误、踩坑记录、实战案例集 |

### 两大优先级定义

| 优先级 | 标识 | 说明 |
|:------:|------|------|
| 核心优先 | ★★★ | 项目启动必备，首批搜集，无此资料则对应智能体无法正常工作 |
| 后期补充 | ★★☆ | 进阶提升资料，项目推进中按需补充 |
