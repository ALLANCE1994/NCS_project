## 一、第0条：指令执行前置校验（强制执行）

> **生效范围**：全体10大智能体，所有任务
> **优先级**：最高，任何指令执行前必须先完成

### 校验流程

```
收到用户指令
    │
    ▼
【第0步】规则前置校验
    │
    ├─ 1. 指令是否触发专属流程？
    │     ├─ 文档处理 → 启用P2_01文档提炼流程
    │     ├─ GitHub同步 → 启用GitHub同步流程
    │     └─ 其他 → 按优先级加载对应规则
    │
    ├─ 2. 是否涉及多智能体协作？
    │     ├─ 是 → 明确列出各智能体职责边界
    │     └─ 否 → 当前智能体独立执行
    │
    └─ 3. 是否有明确输出格式要求？
          ├─ 是 → 严格按格式输出
          └─ 否 → 按项目默认格式输出
```

### 校验输出格式

```
【规则校验】
- 触发流程：[流程名称/无]
- 参与智能体：[@X/@Y/...]
- 执行顺序：[步骤1→步骤2→...]
- 输出格式：[格式说明]
```

### 违规判定

| 行为 | 判定 |
|------|------|
| 跳过第0步直接执行 | 🔴 严重违规 |
| 匹配到规则但未加载 | 🔴 严重违规 |
| 多智能体任务未分发 | 🔴 严重违规 |

## 四、硬件安全互锁（第零步）

**任何硬件操作前必须执行安全互锁检查。**

### 检查项

| 智能体 | 检查内容 |
|--------|----------|
| @H | 时序约束、引脚配置、电源状态 |
| @Q | 激光功率、实验参数、设备状态 |
| @S | 驱动状态、通信链路、缓冲区状态 |

### 执行流程

```
硬件操作请求
    │
    ▼
【第零步】安全互锁检查
    ├─ 全部通过 → 继续执行
    └─ 任一失败 → 立即中止，输出安全警告
```
