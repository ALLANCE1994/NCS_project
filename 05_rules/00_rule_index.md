## 七、规则使用说明

### 7.1 加载顺序

```
项目启动
    │
    ▼
加载 P0 规则（永久常驻）
    │
    ▼
根据任务类型加载对应优先级规则
    │
    ├─ 技术决策/代码开发 → 加载 P1
    ├─ 文档处理/质量验收 → 加载 P2
    └─ 格式优化/外部查询 → 加载 P3
```

### 7.2 冲突解决原则

| 冲突场景 | 解决原则 |
|----------|----------|
| P0 vs P1/P2/P3 | **P0优先**，不可违背 |
| P1 vs P2/P3 | **P1优先** |
| P2 vs P3 | **P2优先** |
| 同优先级冲突 | 以**文件编号小**的为准，或提交@V裁决 |

### 7.3 规则引用关系

| 引用方 | 被引用方 | 说明 |
|--------|----------|------|
| P0_01 | P1_02 | 三层回滚防线详见P1_02 |
| P1_01 | P0_05 | 防幻觉速查卡，完整规则详见P0_05 |
| P1_03 | P0_03 | 前期规划深度，阶段转换条件详见P0_03 |
| P2_02 | P1_04 | 小步快跑，改动边界输入格式详见P1_04 |
