# 项目计划制定规则（波特图格式）

> **规则编号**：P2_06  
> **优先级**：P2（标准优先级）  
> **生效日期**：2026-05-19  
> **维护责任**：@V 工程规则管理师  

---

## 一、规则目的

强制使用**波特图（PERT图/网络图）格式**制定项目计划，**禁止使用时间格式**（开始时间/截止时间），防止因时间压力导致的步骤遗漏和虚假进度。

---

## 二、禁止事项

| 禁止项 | 说明 | 违规后果 |
|--------|------|----------|
| ❌ 设定时间节点 | 不得设定"X月X日完成" | 时间压力导致步骤遗漏 |
| ❌ 甘特图格式 | 不使用时间轴驱动的甘特图 | 容易掩盖依赖关系 |
| ❌ 虚假进度 | 时间到了但任务未真正完成 | 质量无法保证 |
| ❌ 跳过步骤 | 为了赶进度而跳过必要检查 | 引入风险 |

---

## 三、波特图格式规范

### 3.1 核心要素

| 要素 | 说明 | 示例 |
|------|------|------|
| **节点** | 任务单元，有明确交付物 | 节点A：架构设计文档 |
| **边** | 依赖关系，箭头表示先后顺序 | A → B（B依赖A） |
| **关键路径** | 最长依赖链，决定项目最短时间 | A→B→D |

### 3.2 节点定义表

```markdown
### 节点定义
| 节点ID | 任务名称 | 负责人 | 交付物 | 前置条件 | 状态 |
|:------:|----------|--------|--------|----------|:----:|
| A | 任务A | @X | 交付物A | 无 | ⏳ |
| B | 任务B | @Y | 交付物B | A完成 | ⏳ |
| C | 任务C | @Z | 交付物C | A完成 | ⏳ |
| D | 任务D | @W | 交付物D | B+C完成 | ⏳ |
```

### 3.3 依赖关系图（Mermaid）

```markdown
### 依赖关系图
```mermaid
graph LR
    A[任务A<br/>@X] --> B[任务B<br/>@Y]
    A --> C[任务C<br/>@Z]
    B --> D[任务D<br/>@W]
    C --> D
```
```

### 3.4 任务状态定义

| 状态 | 符号 | 说明 |
|:----:|:----:|------|
| 待启动 | ⏳ | 前置条件未满足或尚未开始 |
| 进行中 | 🔄 | 正在执行中 |
| 已完成 | ✅ | 交付物已产出并通过自检 |
| 已验收 | 📋 | 已通过@V审核 |
| 阻塞 | ❌ | 遇到问题无法继续，需上报 |

---

## 四、计划制定流程

```
步骤1：列出所有必要任务
    ↓ 不遗漏任何步骤
步骤2：定义每个任务的交付物
    ↓ 可验证的产出
步骤3：确定任务间依赖关系
    ↓ 谁必须在谁之前
步骤4：绘制依赖关系图
    ↓ Mermaid格式
步骤5：识别关键路径
    ↓ 最长依赖链
步骤6：标记就绪任务
    ↓ 无前置依赖，可立即开始
```

---

## 五、任务完成标准

- [x] **交付物已产出** - 文档/代码/报告等已生成
- [x] **自检通过** - 负责人已完成质量自检
- [x] **@V审核通过** - 工程规则管理师已验收
- [x] **后置任务可启动** - 依赖此任务的后置任务可以开始

**注意**：任务完成不以时间为标准，以**质量验收**为标准。

---

## 六、阻塞处理机制

### 6.1 阻塞上报流程

```
任务阻塞
    ↓
立即上报@M（不得等待）
    ↓
说明具体阻塞原因（等待谁的什么交付物）
    ↓
提供解决方案或替代路径
    ↓
@M协调资源解决或调整计划
```

### 6.2 阻塞原因分类

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| 依赖阻塞 | 等待前置任务交付 | 催促前置任务负责人 |
| 资源阻塞 | 缺少必要资源 | 申请资源或调整计划 |
| 技术阻塞 | 遇到技术难题 | 寻求@P/@Q技术支持 |
| 决策阻塞 | 需要人做出决策 | 上报@C/@M决策 |

## 八、执行要求

### 8.1 必须遵守

- [x] 所有项目计划必须使用波特图格式
- [x] 不得设定时间节点（X月X日完成）
- [x] 任务完成以验收为标准，不以时间为标准
- [x] 阻塞必须立即上报，不得跳过或假设

### 8.2 审核机制

| 审核人 | 审核内容 | 审核时机 |
|--------|----------|----------|

| @V | 任务完成质量 | 任务提交后 |
