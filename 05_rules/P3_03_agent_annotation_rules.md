# 智能体标注规范

> **规则编号**：P3_03  
> **优先级**：P3（辅助优先级）  
> **生效日期**：2026-05-19  
> **维护责任**：@V 工程规则管理师  

---

## 一、规则目的

在工程落地阶段（第三阶段），为明确任务责任人、提高协作透明度，所有任务执行前必须标注智能体名字，让用户直观看出是谁在工作。

---

## 二、标注规范

### 2.1 标注格式

```
【@X 智能体名字】具体工作内容
```

### 2.2 智能体缩写对照表

| 缩写 | 智能体全名 | 主要职责 |
|:----:|------------|----------|
| @C | @C 老板 | 最高决策、需求脱水、审批立项 |
| @M | @M 项目经理 | 任务拆解、进度管理、结果汇总 |
| @P | @P 架构师 | 系统架构设计、技术选型、MVP裁定 |
| @H | @H 硬件工程师 | VHDL编写、IP核配置、Vivado工程 |
| @S | @S 软件工程师 | PYNQ驱动、Jupyter界面、数据处理 |
| @Q | @Q 量子科学家 | NV色心原理、实验方案、参数计算 |
| @V | @V 工程规则管理师 | 合规审核、防幻觉终审、质量管控 |
| @D | @D 文档预处理工程师 | 全格式文件解析、粗加工、领域分发 |
| @E | @E 文档工程师 | 技术文档撰写、实验报告、归档管理 |
| @A | @A AI使用工程师 | 全局调度枢纽 + 永久项目记忆库 |

### 2.3 标注场景

| 场景 | 标注示例 |
|------|----------|
| 代码编写 | `【@H 硬件工程师】VHDL代码实现` |
| 脚本生成 | `【@S 软件工程师】Python数据处理脚本` |
| 设计文档 | `【@P 架构师】系统架构设计` |
| 参数计算 | `【@Q 量子科学家】ODMR参数计算` |
| 代码审核 | `【@V 工程规则管理师】代码审核检查清单` |
| 任务分配 | `【@P 项目经理】开发任务分配` |

---

## 三、执行要求

### 3.1 必须标注的情况

- [x] 代码/脚本编写前
- [x] 设计文档编写前
- [x] 审核/检查工作前
- [x] 任务分配/调度时
- [x] 跨智能体协作时

### 3.2 可选标注的情况

- [ ] 简单对话回复
- [ ] 确认/否定回答
- [ ] 纯信息查询

### 3.3 禁止标注的情况

- [ ] 用户直接输入的内容
- [ ] 系统提示信息
- [ ] 错误/异常信息

---

【@H】代码如下...  ← 不规范：缺少智能体全名
```
