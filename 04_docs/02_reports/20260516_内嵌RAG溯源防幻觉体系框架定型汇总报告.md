## 三、RAG溯源防幻觉铁律

### 3.1 强制溯源场景

所有专业智能体在输出以下**硬核技术内容**前，必须优先检索自身专属私有向量知识库：

| 智能体 | 强制溯源内容 |
|--------|--------------|
| 硬件工程师 | FPGA代码、IP配置、时序约束、IO引脚定义 |
| 软件工程师 | PYNQ驱动、PS-PL交互、DMA配置、Overlay参数 |
| 架构师 | 系统架构方案、SOC资源划分、接口定义、AXI配置 |
| 量子科学家 | NV色心实验原理、物理参数、脉冲序列、数据分析方法 |
| 文档工程师 | 技术文档规范、实验报告格式、归档规则 |

### 3.2 溯源执行规则

| 场景 | 执行规则 |
|------|---------|
| 检索到权威匹配资料 | 严格依托原文输出，标注知识来源，禁止篡改和过度延伸 |
| 未检索到有效内容 | 立刻停止作答，明确告知缺资料，绝不编造 |
| 非技术类内容 | 无需强制溯源，正常输出 |

### 3.3 知识来源标注格式

```
【知识来源】
- 文档名称：《XXX》
- 核心出处：第X章/第X节
- 关键内容：[原文核心描述]
```

## 七、全局执行约束

### 7.1 硬性约束

1. **无实体硬件调试模式**：所有规则仅作用于方案设计、代码框架、文档整理、知识梳理层面
2. **并行运行**：AI自动生成全员基础知识库、双层PDF文档提炼流程、智能体分工协作流程全部正常并行运行
3. **静默生效**：所有防幻觉规则静默生效，不改变原有使用习惯
4. **即时拦截**：若遇到智能体违反溯源规则擅自编造内容，由工程规则管理师第一时间拦截纠正

### 7.2 后续衔接约定

基础知识库打底完成后：

1. 用户陆续上传NV色心实验、ZYNQ硬件、脉冲卡、采集卡、锁相放大器、PYNQ实操等专业PDF资料
2. 沿用固定流程：文档预处理工程师粗加工→对应专业智能体深度精炼→规则师审核→归档专属专业知识库→用户确认后批量入库
3. 基础通用知识+项目专业知识双向融合，让智能体既懂本职规矩，又精通本项目业务
