### 2.2 FPGA核心模块

#### 2.2.1 频率捷变控制模块

| 参数 | 配置 |
|------|------|
| **FPGA平台** | Xilinx ZYNQ7020 SOC (ALINX载板) |
| **SPI时钟** | 100 MHz |
| **NCO位数** | 48-bit |
| **信号源** | CN0511 (ADI, 内置AD9166) |
| **频率控制字** | 6字节数据 + 2字节地址 |
| **幅度控制字** | 2字节数据 + 2字节地址 |
| **跳频时间** | 980 ns (8字节@100MHz SPI) |

**工作原理**：
- FPGA通过高速SPI向CN0511写入48-bit频率控制字
- AD9166内部NCO根据频率字生成GHz级单音信号
- 支持动态频率切换，无需重新配置整个PLL

#### 2.2.2 调制信号生成模块

| 参数 | 配置 |
|------|------|
| **DAC** | AN9767 (14-bit, ALINX) |
| **载波频率** | 10 MHz |
| **调制频率** | 10 kHz (优化参数) |
| **调制深度** | 2 MHz (优化参数) |
| **实现方式** | 双ROM核DDS |

**DDS实现细节**：
- ROM核1：存储10kHz调制波（14-bit深度正弦数据）
- ROM核2：存储10MHz载波（14-bit深度正弦数据）
- 通过频率控制字灵活调整读出地址，生成可变参数调制波

#### 2.2.3 正交数字锁相放大器 (DLIA)

| 参数 | 配置 |
|------|------|
| **架构** | 正交相位锁定 (I/Q双通道) |
| **ADC** | 16-bit, 80 MSPS |
| **前级运放** | 噪声密度 1.1 nV/√Hz |
| **滤波器** | 级联FIR + 离散时间RC |
| **解调时间** | ~80 μs (0%→90%响应) |

**信号处理流程**：
```
荧光信号(含噪声) → 16位ADC → 数字混频(×参考信号) 
    → 级联低通滤波(FIR+RC) → 幅度/相位输出
```

## 三、核心算法与参数

### 3.1 磁场计算公式

**NV色心共振频率与磁场关系**：

```
f = 2.87 GHz ± γ·B·cosθ
Δf = 2γ·B·cosθ
```

其中：
- γ = 2.8 MHz/Gs (旋磁比)
- B = 磁场强度
- θ = 磁场与NV轴夹角

**电流-磁场标定方程**：
```
B = 7.2026·I - 0.089  (Helmholtz线圈)
B_II = 1.42674·B_I - 0.4324  (NV测量值转换)
```

## 四、实验验证

### 4.1 频率跳变测试

**测试方法**：
- 示波器监测频率切换后的幅度控制响应
- 幅度控制在频率控制字后320ns生效（4字节32位传输时间）
- 总跳频时间 = 6字节频率字 + 2字节地址 = 8字节 = 80时钟周期@100MHz = 800ns + 开销 = **980ns**

### 4.2 解调时间测试

**测试方法**：
- 输入带白噪声的低频信号到FPGA
- 测量经过低通滤波后解调信号稳定时间
- 定义：输出从0%上升到90%最终幅度的时间
- 结果：**~80 μs**

### 4.3 电流测量精度测试

**测试设置**：
- 双层Helmholtz线圈（圆柱形，上下分区绕制）
- Keysight高稳定性电流源
- NV样品位于线圈中心（磁场最大处）
- Gaussmeter标定线圈磁场

**结果**：
- 0-10 A范围内相对误差 < 0.08%
- 线性拟合方程：B = 7.2026·I - 0.089

### 5.2 与调研-1的关联

本论文实现的是**连续波ODMR (CW-ODMR)** 快速测量系统，与调研-1推荐的**#14动力学去耦**论文形成互补：

| 对比项 | P6 (本论文) | #14动力学去耦 |
|--------|-------------|---------------|
| 测量模式 | CW-ODMR (连续波) | Pulsed ODMR (脉冲) |
| 核心优势 | 快速响应 (<1μs跳频, <80μs解调) | 相干时间延长25倍 |
| FPGA重点 | 频率捷变 + 锁相解调 | 脉冲序列发生器 |
| 适用场景 | 动态磁场跟踪 | 高精度静态测量 |
| 可合并性 | **高** | 可整合为完整系统 |

**建议整合方案**：
- Phase 1：复现P6的CW-ODMR快速测量（本论文）
- Phase 2：叠加P3的脉冲发生器，实现动力学去耦
- Phase 3：融合为可切换双模式系统

| 模块 | 实现难度 | 参考资源 |
|------|----------|----------|
| SPI频率控制驱动 | 低 | 论文描述清晰，Linux SPI子系统 |
| 双ROM核DDS | 低 | 标准DDS原理，Vivado DDS Compiler IP |

### 6.3 关键挑战

1. **微波源选择**：
   - 方案A：采购CN0511（性能最优，成本较高）
   - 方案B：ADF4351 + 外部调制（成本较低，需更多开发）

2. **滤波器参数调优**：
   - 级联FIR + RC滤波器的截止频率需实验优化
   - 目标：在保证带宽的前提下最小化解调时间

3. **相消噪声抑制**：
   - 需要精确的光路对准和时域匹配
   - 参考光路与信号光路的光程差控制
