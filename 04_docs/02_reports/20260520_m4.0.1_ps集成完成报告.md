### 1.2 架构变更

**M3(纯PL)**:
```
外部50MHz时钟 → top_odmr → DDS/ADC/SCAN/CORDIC/IIR
```

**M4(PS+PL)**:
```
PS7 (ARM Cortex-A9)
    ├── FCLK_CLK0 (50MHz) → top_odmr (PL时钟)
    ├── FCLK_RESET0_N → top_odmr (PL复位)
    └── M_AXI_GP0 → AXI Interconnect → top_odmr (AXI4-Lite Slave)
                                              ├── 寄存器阵列(16×32bit)
                                              ├── DDS控制
                                              ├── 扫描控制
                                              └── 数据读取
```

## 二、AXI-Lite寄存器映射

| 地址偏移 | 名称 | 类型 | 位宽 | 说明 |
|:--------:|------|:----:|:----:|------|
| 0x00 | CTRL | R/W | 32 | 全局控制([0]=EN, [1]=DDS_EN, [2]=SCAN_EN) |
| 0x04 | STATUS | R | 32 | 状态([0]=SCAN_BUSY, [1]=SCAN_DONE, [2]=ADC_OVF, [3]=LIA_BUSY) |
| 0x08 | DDS_FREQ | R/W | 32 | DDS频率控制字 |
| 0x0C | DDS_PHASE | R/W | 32 | DDS相位偏移 |
| 0x10 | SCAN_START_FREQ | R/W | 32 | 扫描起始频率 |
| 0x14 | SCAN_STOP_FREQ | R/W | 32 | 扫描终止频率 |
| 0x18 | SCAN_STEP | R/W | 32 | 扫描步进 |
| 0x1C | SCAN_DWELL | R/W | 32 | 驻留时间(低16位) |
| 0x20 | SCAN_POINTS | R/W | 32 | 扫描总点数(低16位,PS预计算) |
| 0x24 | SCAN_CTRL | R/W | 32 | 扫描控制([0]=START, [1]=STOP) |
| 0x28 | ADC_DATA | R | 32 | ADC数据([15:0]有效) |
| 0x2C | LIA_MAG | R | 32 | 锁相幅值([15:0]有效) |
| 0x30 | LIA_PHASE | R | 32 | 锁相相位([15:0]有效) |
| 0x34 | IIR_DATA | R | 32 | IIR滤波数据([15:0]有效) |
| 0x38 | CURRENT_FREQ | R | 32 | 当前DDS频率 |
| 0x3C | POINT_COUNT | R | 32 | 当前扫描点计数(低16位) |

## 三、代码变更统计

### top_odmr.vhd 变更

| 变更项 | 说明 |
|--------|------|
| 端口 | 移除`sys_clk_50m`/`sys_rst_n`, 新增完整AXI4-Lite从接口(23个信号) |
| 内部信号 | 新增`regs`寄存器阵列(16×32bit), AXI控制信号 |
| AXI写逻辑 | 地址解码+寄存器写入(0x00-0x24可写) |
| AXI读逻辑 | 地址解码+寄存器读出(0x00-0x3C可读) |
| 子模块连接 | 所有控制信号改为从`regs`读取 |
| 时钟源 | `sys_clk = s_axi_aclk` (PS7 FCLK_CLK0) |
| 复位源 | `rst_n = not s_axi_aresetn` (PS7 FCLK_RESET0_N) |

**代码行数**: 约+120行 (符合P0_08小步快跑)
