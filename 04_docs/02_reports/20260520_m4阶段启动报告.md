**当前寄存器定义**（来自M2阶段）:

| 地址 | 寄存器 | 说明 |
|------|--------|------|
| 0x00 | CTRL | 控制寄存器 |
| 0x04 | STATUS | 状态寄存器 |
| 0x08 | FREQ_CTRL | 频率控制（DDS） |
| 0x0C | PHASE_OFFSET | 相位偏移（DDS） |
| 0x10 | SCAN_START | 扫描起始频率 |
| 0x14 | SCAN_STOP | 扫描终止频率 |
| 0x18 | SCAN_STEP | 扫描步进 |
| 0x1C | **SCAN_POINTS** | 扫描点数（新增） |

> ⚠️ 注意: M3.6修复新增了`total_points`输入，需在M4中配置

class ODMROverlay(Overlay):
    """NV色心ODMR实验系统Overlay"""
    
    def __init__(self, bitfile, **kwargs):

    """DDS信号发生器驱动"""

class ScanDriver:

    def stop_scan(self) -> None: ...
    @property
    def is_busy(self) -> bool: ...

### 6.2 扫描点数计算公式

```python
def calculate_scan_points(freq_start: int, freq_stop: int, freq_step: int) -> int:
    """计算ODMR扫描点数
    
    Args:
        freq_start: 起始频率(Hz)
        freq_stop: 终止频率(Hz)
        freq_step: 频率步进(Hz)
    
    Returns:
        扫描点数(16位无符号整数)
    """
    if freq_step <= 0:
        return 1
    freq_range = freq_stop - freq_start
    points = int(freq_range / freq_step) + 1
    return min(points, 65535)  # 限制在16位范围
```
