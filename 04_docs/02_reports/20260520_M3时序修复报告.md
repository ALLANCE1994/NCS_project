## 一、问题描述

### 1.1 时序违例概况

| 指标 | 修复前 | 目标值 |
|------|--------|--------|
| WNS (Worst Negative Slack) | **-43.919ns** | > 0ns |
| TNS (Total Negative Slack) | -698.535ns | = 0ns |
| 失败端点 | 16个 | 0个 |
| 逻辑层级 | 238层 | < 10层 |

### 1.2 关键路径分析

```
源寄存器:      inst_scan_controller/freq_step_reg_reg[3]/C
目标寄存器:    inst_scan_controller/total_pts_reg[14]/D
数据路径延迟:  63.940ns (逻辑67.5% + 布线32.5%)
逻辑层级:      238层 (CARRY4=206, LUT=32)
时钟周期:      20ns (50MHz)
```

### 1.3 根因定位

**问题代码位置**: `scan_controller.vhd` 第176行

```vhdl
-- 原代码：32位除法在单周期完成
pts_calc := resize(freq_range / freq_step_reg, POINT_WIDTH) + 1;
```

**问题本质**: 32位除法操作产生238层组合逻辑，延迟63.940ns远超20ns时钟周期。

## 二、修复方案

### 2.1 方案选择

| 方案 | 描述 | 优缺点 | 选择 |
|------|------|--------|:----:|
| A | 多周期除法器 | 硬件复杂，需状态机控制 | ❌ |
| B | **PS端预计算** | 软件端计算，硬件仅加载 | ✅ |
| C | 查找表近似 | 精度损失，增加BRAM使用 | ❌ |

**选择理由**:
1. 扫描点数计算频率低（仅扫描开始时一次）
2. PS端Python计算简单高效
3. 符合PS-PL分工原则
4. 修改量小，符合P0_08小步快跑规则

### 2.2 代码变更

#### 变更1: scan_controller.vhd - 实体端口

```vhdl
-- 【新增】由PS端预计算传入的扫描总点数
total_points_in : in  std_logic_vector(POINT_WIDTH-1 downto 0);
```

#### 变更2: scan_controller.vhd - 扫描点数计算

```vhdl
-- 【移除】32位除法操作（238层组合逻辑）
-- pts_calc := resize(freq_range / freq_step_reg, POINT_WIDTH) + 1;

-- 【新增】直接使用PS端传入的预计算值
if state = IDLE and start_scan = '1' then
    total_pts <= unsigned(total_points_in);
end if;
```

#### 变更3: top_odmr.vhd - 信号声明

```vhdl
signal scan_total_pts : std_logic_vector(15 downto 0);  -- 【新增】
```

#### 变更4: top_odmr.vhd - 默认值赋值

```vhdl
scan_total_pts <= X"03E8";  -- 默认1000点
```

#### 变更5: top_odmr.vhd - 实例化连接

```vhdl
total_points_in => scan_total_pts,  -- 【新增】
```

## 五、后续工作

### 5.1 软件端配合修改

PS端Python代码需要预计算扫描点数：

```python
# Python端预计算扫描点数
def calculate_scan_points(freq_start, freq_stop, freq_step):
    """计算ODMR扫描点数"""
    if freq_step == 0:
        return 1
    freq_range = freq_stop - freq_start
    points = int(freq_range / freq_step) + 1
    return min(points, 65535)  # 限制16位范围

# 配置扫描参数时传入
total_points = calculate_scan_points(2.87e9, 2.97e9, 1e6)
overlay.scan_controller_0.write(0x14, total_points)  # 写入寄存器
```
