## 五、新增P0级规则

### P0_06 阶段闸门强制机制

```
规则名称：阶段闸门强制检查

内容：
1. 任何阶段开始前，必须检查上一阶段出口条件
2. @V必须在每个阶段结束时出具合规报告
3. 未通过@V审核，禁止进入下一阶段
4. 违反者强制回退，已工作作废

执行方式：
- 在TCL脚本/代码中添加阶段检查标记
- @V每日检查各智能体工作边界
- 用户指令若违反阶段顺序，必须拒绝并说明
```

### P0_07 架构文档强制评审

```
规则名称：架构文档强制评审

内容：
1. 任何代码编写前，必须有对应的架构文档
2. 引脚分配必须有引脚规划文档
3. 时序约束必须有时序预算分析
4. 文档必须经过@A @V @P三方评审

检查清单：
- [ ] 系统架构图（Mermaid）
- [ ] 模块接口定义
- [ ] 引脚分配规划
- [ ] 时钟树架构
- [ ] 复位策略
- [ ] AXI寄存器映射
```

### P0_08 小步快跑强制执行

```
规则名称：小步快跑强制执行

内容：
1. 单步修改不超过50行代码
2. 每步必须有明确的验证目标
3. 每步必须通过@V合规检查
4. 禁止"一步到位"式开发

验证标准：
- 综合通过（synthesis）
- 时序满足（WNS>0）
- 功能仿真通过（如有）
- @V签字确认
```
