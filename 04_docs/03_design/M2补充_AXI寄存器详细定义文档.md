## 一、寄存器总览

### 1.1 地址空间

| 参数 | 值 | 说明 |
|------|-----|------|
| 基地址 | 0x4000_0000 | PS7分配给PL的地址空间 |
| 地址范围 | 0x4000_0000 ~ 0x4000_0FFF | 4KB |
| 寄存器数量 | 16 | 32位寄存器 |
| 数据宽度 | 32位 | AXI4-Lite标准 |
| 地址对齐 | 4字节 | 地址[1:0]=00 |

### 1.2 寄存器分类

| 类别 | 寄存器 | 地址范围 | 说明 |
|------|--------|----------|------|
| 全局控制 | CTRL, STATUS | 0x00~0x04 | 系统使能/状态 |
| DDS控制 | DDS_FREQ, DDS_PHASE | 0x08~0x0C | DDS频率/相位 |
| 扫描控制 | SCAN_START~SCAN_CTRL | 0x10~0x24 | 扫描参数/控制 |
| 数据读取 | ADC_DATA~POINT_COUNT | 0x28~0x3C | 采集数据/状态 |

## 二、寄存器详细定义

### 2.1 全局控制寄存器

#### 0x00 CTRL - 控制寄存器

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [0] | GLOBAL_EN | R/W | 0 | 全局使能（1=使能所有模块） |
| [1] | DDS_EN | R/W | 0 | DDS使能 |
| [2] | SCAN_EN | R/W | 0 | 扫描使能 |
| [3] | SOFT_RST | R/W1C | 0 | 软件复位（写1复位，自动清零） |
| [31:4] | Reserved | - | 0 | 保留，写0读0 |

**写时序**:
```
T0: AWVALID=1, AWADDR=0x00
T1: AWREADY=1, WVALID=1, WDATA=0x0000_0007 (EN+DDS_EN+SCAN_EN)
T2: BVALID=1, BRESP=00 (OKAY)
```

#### 0x04 STATUS - 状态寄存器

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [0] | SCAN_BUSY | R | 0 | 扫描进行中（1=忙） |
| [1] | SCAN_DONE | R | 0 | 扫描完成（脉冲，读自动清零） |
| [2] | ADC_OVF | R | 0 | ADC溢出标志 |
| [3] | LIA_BUSY | R | 0 | 锁相处理中 |
| [31:4] | Reserved | - | 0 | 保留 |

**读时序**:
```
T0: ARVALID=1, ARADDR=0x04
T1: ARREADY=1, RVALID=1, RDATA=0x0000_0001 (SCAN_BUSY)
```

---

### 2.2 DDS控制寄存器

#### 0x08 DDS_FREQ - DDS频率控制字

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [31:0] | FREQ_CTRL | R/W | 0x0000_0000 | DDS频率控制字（32位相位累加器） |

**频率计算公式**:
```
F_out = (FREQ_CTRL / 2^32) * F_clk
FREQ_CTRL = (F_out / F_clk) * 2^32

示例: F_out=2.87GHz, F_clk=1GHz (DDS内部时钟)
FREQ_CTRL = 0x4CCCCCCD (约1.23e9)
```

#### 0x0C DDS_PHASE - DDS相位偏移

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [31:0] | PHASE_OFFSET | R/W | 0x0000_0000 | DDS相位偏移（32位，0~2π） |

---

### 2.3 扫描控制寄存器

#### 0x10 SCAN_START_FREQ - 扫描起始频率

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [31:0] | START_FREQ | R/W | 0x0000_0000 | 扫描起始频率（Hz，32位无符号） |

**典型值**: 0x04CCCCCC = 80,000,000 (80MHz，对应2.87GHz实际频率)

#### 0x14 SCAN_STOP_FREQ - 扫描终止频率

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [31:0] | STOP_FREQ | R/W | 0x0000_0000 | 扫描终止频率（Hz，32位无符号） |

**典型值**: 0x05C28F5C = 96,000,000 (96MHz，对应2.97GHz实际频率)

#### 0x18 SCAN_STEP - 扫描步进

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [31:0] | FREQ_STEP | R/W | 0x0000_0000 | 频率步进（Hz，32位无符号） |

**典型值**: 0x00001388 = 5,000 (5kHz步进)

#### 0x1C SCAN_DWELL - 驻留时间

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [15:0] | DWELL_TIME | R/W | 0x03E8 | 每点驻留时间（时钟周期数） |
| [31:16] | Reserved | - | 0 | 保留 |

**典型值**: 0x03E8 = 1000 (1000个时钟周期 = 20μs @50MHz)

#### 0x20 SCAN_POINTS - 扫描总点数

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [15:0] | TOTAL_POINTS | R/W | 0x0000 | 扫描总点数（16位无符号） |
| [31:16] | Reserved | - | 0 | 保留 |

**计算公式**:
```
TOTAL_POINTS = (STOP_FREQ - START_FREQ) / FREQ_STEP + 1

示例: (96MHz - 80MHz) / 5kHz + 1 = 3201点
```

**注意**: 此值由PS端Python预计算后写入，PL端不再做除法运算。

#### 0x24 SCAN_CTRL - 扫描控制

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [0] | START | R/W1C | 0 | 写1启动扫描（自动清零） |
| [1] | STOP | R/W1C | 0 | 写1停止扫描（自动清零） |
| [31:2] | Reserved | - | 0 | 保留 |

**扫描启动流程**:
```
1. 配置 SCAN_START_FREQ (0x10)
2. 配置 SCAN_STOP_FREQ (0x14)
3. 配置 SCAN_STEP (0x18)
4. 配置 SCAN_DWELL (0x1C)
5. 配置 SCAN_POINTS (0x20)
6. 写 SCAN_CTRL[0]=1 (0x24) 启动扫描
```

---

### 2.4 数据读取寄存器

#### 0x28 ADC_DATA - ADC采集数据

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [13:0] | ADC_VALUE | R | 0 | ADC采集值（14位有符号） |
| [31:14] | Reserved | - | 0 | 保留 |

#### 0x2C LIA_MAG - 锁相幅值

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [15:0] | MAGNITUDE | R | 0 | CORDIC输出幅值（16位无符号） |
| [31:16] | Reserved | - | 0 | 保留 |

#### 0x30 LIA_PHASE - 锁相相位

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [15:0] | PHASE | R | 0 | CORDIC输出相位（16位，-π~+π） |
| [31:16] | Reserved | - | 0 | 保留 |

#### 0x34 IIR_DATA - IIR滤波数据

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [15:0] | FILTERED | R | 0 | IIR滤波输出（16位有符号） |
| [31:16] | Reserved | - | 0 | 保留 |

#### 0x38 CURRENT_FREQ - 当前频率

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [31:0] | CUR_FREQ | R | 0 | 当前DDS输出频率（Hz） |

#### 0x3C POINT_COUNT - 当前点计数

| 位域 | 名称 | 类型 | 默认值 | 说明 |
|:----:|------|:----:|:------:|------|
| [15:0] | COUNT | R | 0 | 当前扫描点计数（0~TOTAL_POINTS-1） |
| [31:16] | Reserved | - | 0 | 保留 |

## 五、PYNQ寄存器访问示例

```python
from pynq import Overlay

# 加载Overlay
ol = Overlay('odmr_zynq7020.bit')

# 获取AXI-Lite IP（自动识别地址映射）
odmr = ol.top_odmr

# 写DDS频率（2.87GHz）
odmr.write(0x08, 0x04CCCCCD)

# 写DDS相位（0）
odmr.write(0x0C, 0x00000000)

# 使能DDS
odmr.write(0x00, 0x00000003)  # GLOBAL_EN=1, DDS_EN=1

# 配置扫描参数
odmr.write(0x10, 0x04CCCCCC)  # START_FREQ
odmr.write(0x14, 0x05C28F5C)  # STOP_FREQ
odmr.write(0x18, 0x00001388)  # STEP
odmr.write(0x1C, 0x000003E8)  # DWELL
odmr.write(0x20, 0x00000C81)  # POINTS = 3201

# 启动扫描
odmr.write(0x24, 0x00000001)  # START=1

# 读取状态
status = odmr.read(0x04)
if status & 0x01:
    print("扫描进行中...")

# 读取ADC数据
adc_data = odmr.read(0x28) & 0x3FFF
```
