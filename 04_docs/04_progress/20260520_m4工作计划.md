## 三、技术方案选择

### 方案A: 添加PS系统（PYNQ方案）

**前提条件**：Vivado工程中添加ZYNQ Processing System

| 优点 | 缺点 |
|------|------|
| PYNQ官方支持 | 需要重新综合/实现 |
| Jupyter直接控制 | Vivado工程变更 |
| Overlay生态 | 增加复杂度 |

**步骤**：
1. Vivado中创建Block Design
2. 添加ZYNQ PS7 IP
3. 配置DDR/时钟/复位
4. 添加AXI GPIO/UART
5. 综合 → 实现 → 生成.bit+.hwh

### 方案B: 纯TCP方案（当前可行）

**前提条件**：无需修改Vivado工程

| 优点 | 缺点 |
|------|------|
| 立即可用 | 非PYNQ标准方式 |
| 无需重新综合 | 需要自定义协议 |
| M3.bit可直接用 | 缺少Overlay生态 |

**步骤**：
1. 开发TCP服务器（PS端Python）
2. 定义寄存器读写协议
3. 开发PC客户端
4. Jupyter通过TCP控制
