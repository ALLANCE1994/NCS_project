## 二、工程对标：可直接复用的开源方案

### P3：纳秒级反馈FPGA设备（开源）

| 项目 | 内容 |
|------|------|
| **来源** | AIP Advances 13, 115324 (2023) |
| **开源地址** | https://github.com/leaferfoeget/real-time-feedback |
| **FPGA** | Artix-7 xc7a75t（33K逻辑单元） |
| **脉冲分辨率** | **1 ns** |
| **时间标签精度** | **10.5 ps** |
| **反馈延迟** | **8 ns** |

**可直接复用的模块：**
- 20通道脉冲流发生器（500MHz双边沿解码）
- TDL-TDC时间标签器（进位链抽头延迟线）
- MAD自适应判决算法

**XC7Z020适配：**
- ✅ 资源充裕（33K → 53K逻辑单元）
- ✅ 开源代码可直接参考修改
- ⚠️ 需针对XC7Z020重新校准TDC延迟特性

### P6：ZYNQ7020快速磁场测量（同平台）

| 项目 | 内容 |
|------|------|
| **来源** | J. Phys.: Conf. Ser. 3216 (2026) |
| **FPGA** | **Xilinx ZYNQ7020 SOC**（ALINX载板） |
| **ADC** | 16位, 80 MSPS |
| **频率跳变** | **< 1 μs**（实测980 ns） |
| **解调响应** | **< 80 μs** |
| **灵敏度** | **8.3 nT/√Hz** |

**可直接复用的技术：**
- 100MHz SPI + 48-bit NCO频率捷变方案
- 正交锁相+级联FIR/RC滤波（80μs解调）
- 相消噪声抑制（参考光路时域消除）

**XC7Z020适配：**
- ✅ **芯片平台完全一致**，参考价值最高
- ✅ 可直接移植到我们的ALINX板
- ⚠️ CN0511信号源需额外采购
